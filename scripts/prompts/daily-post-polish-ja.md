役割: この稿の校正者。著者ではない。

対象: `src/content/blog/ja/{{SLUG}}.md` の一ファイルだけ。

目的: 著者の自然な文体とリズムを尊重し、明らかな誤字、不自然な翻訳調、波ダッシュなどの記号違反のみを整える。無理に文を削ったり解体したりしない。

先に `data/column-brief.md` を読む。事実の判定基準はこれだけ。

やらないこと:
- 事実・数値・引用・主張の追加。ブリーフにないものは入れない。
- 段落の全面書き直しや不自然な文の寸断。著者の語順と語彙を残す。
- 導入・要約・締めの段落の追加。
- 因果説明、専門用語の解説、失敗や留保の削除。
- 再現コマンド、コードブロック、計測出力の削除。

点検して直すこと:
1. 明らかな誤字脱字、不自然な機械翻訳調の表現。
2. 指す先が曖昧な指示語（それ・これ・当該 → 実際の名前に）。
3. 波ダッシュ・波線記号(`~`, `〜`, `～`)を全量削除し、ハイフン(`-`)や「AからBまで」に置き換える。
4. キーボードにない非標準記号(`─ → ⚠`)や見出しの絵文字の整理。

直したあと、ファイルに注記を足さない。説明は stdout にだけ出す:

```
POLISH: <前の文字数> → <後の文字数>
- 大きい変更を3-5行
```

質問しない。
