書き方:
- **この稿は `thesis` のために書く。** 数字はその主張の証拠であって、稿の目的ではない。測定を並べて終われば実験ノートだ。
- `counter` を本文で正面から扱う。弱く要約して倒さない。その反対が正しい範囲を認めた上で、それでも `thesis` が立つ理由を書く。反対が勝つ条件があるならそれも書く。
- `decision` を稿の中に明示する。読者は明日なにを変えるのか。
- `does-not-generalize` を隠さない。範囲を自分で先に引くことがこのブログの信用だ。
- 書き出しは FACT CORE の `scene` か `numbers`。日付とガイド名で始めない。結論の先出しもしない。数えた異常から入る。
- 術語は定義文で始めない。先に対象と働きを書き、必要なら三文目で名前を付ける。製品名は原綴りのまま(Cline, Claude Code)。括弧で語義を添えるのは稿全体で三つまで。論の要になる語だけに使う。同じ段落で二度出たら、その段落を書き直す。
- 節ごとに形を変える。全部が「主張 → 列挙 → 留保」で終わってはいけない。コマンドと出力だけで閉じる節、判断だけで閉じる節を混ぜる。
- 一つおきの節に、その日に手を動かした跡を入れる。打ったコマンド、開いたファイル、外れた予想、やらなかったこと。
- 一つの概念には一つの語だけを使う。反復を避けるために同じ対象を文ごとに言い換えない。
- 手順は実際に起きた順に書く。原因と結果は両方を文に出す。結果だけ書いて原因を匂わせない。
- 漢語の肩書き(認知的負債、本質的複雑さ)を使うなら、直後に和語の言い換えを置く。
- 数字は飾りにしない。時間、行数、件数、割合は、自分が数えた／走らせたものだけ書く。比較の対がある形で出す。45行と106行。
- 利害は「重要だ」ではなく、誰が何を失うかで書く。
- エンジニア以外を本文に同席させる。誰が何を見てどう判断したかを、講義ではなく出来事として書く。
- 引用の直後に、同じ内容を日本語で言い直さない。
- 英語技術文の名詞列を日本語に残さない。主語を立て、名詞を動詞に戻し、助詞で文を割る。段落冒頭で前段を言い直して繋がない。
- 「見ていきましょう」「まとめますと」「AではなくB」の対句、コロンだらけの説明、全セクション均等な丁寧さは捨てる。興味のある箇所は厚く、退屈な箇所は短くする。
- 太字は節に一、二箇所まで。地の文でダッシュを使わない。中黒の安易な並列は助詞か読点に替える。
- 表は比較が本体のときだけ。基本は散文。
- H2 はこの稿独自。英語や韓国語の目次を移さない。見出しだけ追っても話の骨が見えるようにする。
- FACT CORE にない数字・引用は書かない。
- **記録されていない差分を分解しない。** 40px から 90px に増えたとだけあるなら、二つの値を書いて止まる。増えた 50px の理由を FACT CORE が言っていないなら、こちらも言わない。もっともらしい因果を埋める場所が、この稿で事実が崩れる場所だ。
- FACT CORE の `commands` は本文に残す。読者がそのままコピーして走らせられること。再現コマンドが一つもない記事は実測記事ではない。
- **本文にコロン(:／：)を使わない。** 見出しの「主題: 副題」、文中の「要点はこうだ:」、箇条書きの「項目: 説明」、導入の「以下のとおり:」すべて含む。コロンが一つ入ると、その行から機械の文に見える。
  - 見出しはコロンなしで一文か一つの名詞句にする。
  - 説明を足すなら文をもう一つ書く。「分散ロック: 同時アクセスを防ぐ仕組み」ではなく「分散ロックは同時アクセスを防ぐ」。
  - 箇条書きも文で書く。
  - 例外はコードブロック、インラインコード、URL、frontmatter、時刻表記だけ。その中のコロンは触らない。
- 「特徴：」「強み：」「手順：」「重要：」のようなラベル行を作らない。ラベルを消して動詞で始まる一文にする。文末の全角コロンも同じだ。
- 引用ブロックには出典リンクをその場で付ける。引用の下に `> — [文書名](URL)` の一行でよい。FACT CORE の `quotes` に URL があるのに本文へ移さなければ、読者は照合できない。
- `relatedPosts` の `reason.ko`・`reason.ja`・`reason.en`・`reason.zh` はそれぞれその言語で書く。日本語の欄に韓国語を入れると、日本語画面にそのまま出る。
- 他言語のブログフォルダを開かない。

書き終えたら音読する。接続詞の密度、文末の反復、確認していない一般論、予告と総括の自己言及を削る。残った文が状況を更新しているか、それとも文書を更新しているだけかを見る。後者は消す。このファイル以外は触らない。
