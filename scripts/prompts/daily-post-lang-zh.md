## 锁住的和自由的

只有 brief 里 `## LOCKED` 块中的数字、引文、日期、出处是锁住的。
其余全部由你决定。

可以把背景铺开，可以做对比，可以用一个比喻，可以设想读者的处境。
业内发生过什么，你知道的就写。这个工具为什么现在出现，从前类似的尝试后来怎样了，
你判断它会往哪走，都写。

只要不把没做过的事写成做过的就行。

`## OPEN` 块是材料，不是脚本。别照着上面的顺序抄。

## 骨架

九块里选六到八块。顺序你定。
选四块以下就写浅了，九块全用就变成目录。
选的时候避开其他语言版本的顺序。

事实梳理 / 机制与结构 / 核对数字 / 成本 / 比较维度 /
**明确的反方(整整一节，必须有)** / 可执行性 / 适合谁 / 局限

篇幅由内容决定。没有目标字数——不为凑数而扩写，也不为达标而删减。H2 六到十个。

## 写

- 第一段用一件带日期的事，或者你真的被问到的问题开头。
- 第二段先给结论。这是让人往下读的理由，不是摘要。
- 不写坦白自己没做过什么的段落。「我没能亲自跑」「沙箱没起来」这类自我声明，
  每篇都挂上去，本身就成了模板。
- 不编 LOCKED 以外的数字、引文、日期。
- 引文块正下方就放出处链接。`> — [文档名](URL)` 一行即可。
- 拿整整一节写 brief 里的 `counter`。不要缩写成一个弱版本再打倒它。
  承认它成立的范围，然后写为什么你的判断依然站得住。
- 不用平衡收尾。选一边，再写一行说明什么条件下这个选择是错的。
- 最后一节不要用总结、教训、`必须要〜` 收尾。最后一句是越过主题的观察。
- 用括号解释术语全文最多三处。其余换成好懂的说法，或者在句子里把它做的事写出来。
- 以书面语为主，夹短句。不写虚化动词(进行、开展、予以)，不写被字句，
  能用主动就用主动。不要四字对仗连发。
- H2 只属于这篇中文稿。不要把别的语言的目录搬过来。
- `relatedPosts` 里的 `reason.ko`、`reason.ja`、`reason.en`、`reason.zh`
  各用各自的语言写。
- 最后一个 H2 是 `## 参考资料`。按 LOCKED `sources[]` 的编号顺序列出链接。
- 不打开别的语言的目录。
- 需要图版就用 `scripts/render-figure.py --slug {{SLUG}} --spec <json> --name figure-1`。
  只有三种 — `two-column`、`matrix`、`before-after`。没有的图就不画。
