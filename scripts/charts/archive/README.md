# 아카이브 — 1회용 도판 스크립트

글 하나당 파일 하나로 만들어진 스크립트들이다. 전부 슬러그가 파일 안에
하드코딩돼 있고 인자를 받지 않는다. 재사용이 안 되므로 여기로 옮겼다.

지우지 않는 이유는 팔레트 사용례이기 때문이다. 카드·화살표·매트릭스를 어떻게
그렸는지 보려면 여기를 연다. 특히 `chart-official-geo-gsc-control.py` 가
현행 크림 팔레트의 원형이다.

`chart-modern-web-guidance.py` 와 `chart-speakable-selectors.py` 두 개는 흰
배경 구세대 팔레트다. 되살리지 않는다.

새 도판은 `scripts/render-figure.py --slug --spec` 로 그린다.
