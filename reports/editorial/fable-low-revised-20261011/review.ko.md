# 03·04편 수정 및 Fable Low 재평가

2026-10-11. 한국어 정본을 수정한 뒤 Claude Desktop의 **Fable 5.1 / 낮음(Low)**으로 각 글의 기존 평가 세션에서 두 차례씩 확인했다. 실제 Read 도구의 파일 열람과 완료 응답을 화면에서 확인했다. 이 보고서는 Codex의 평가 응답 정리이며, 모델이 파일로 저장한 원문이나 새 프롬프트 실행 결과가 아니다.

## 03 수정

- 콘텐츠 자체에 분기·상호작용이 있으면 SC 1.2.1의 음성 전용·영상 전용 정의에 해당하지 않는 이유를 설명했다. 일반 재생·일시 정지 조작은 콘텐츠 분기와 구별했다. [W3C 공식 해설의 정의](https://www.w3.org/WAI/WCAG22/Understanding/audio-only-and-video-only-prerecorded.html#key-terms)를 이번 작업에서 다시 확인했다.
- 세 화면 도식·네 단계 설명·다섯 화면 도식이 별도의 가상 예시임을 설명하고 실제 실습 영상·실행 기록과 구분했다.
- 반복이 다른 항목을 평가한 기존 대화에서 분기한 것이며 빈 독립 세션은 아니고 사례는 순차 처리됐음을 명확히 했다.
- 이전 글과 개요 링크를 모두 canonical 절대 URL로 맞춰 기존 언어별 렌더 치환 규칙을 적용할 수 있게 했다.

최종 응답 발췌:

> 최종 본문 판정: 공개 권고. 남는 본문 필수 문제 없음.

평가자는 본문·프롬프트의 새 문제를 발견하지 않았고, 남은 개요 링크 권장도 해소됐다고 확인했다. 기존 승인값과 변경본의 해시가 다른 상태는 공개 게이트가 미승인 편집본을 차단하는 정상 동작이며 본문 편집 오류가 아니라고 최종적으로 정정했다.

세션: `local_d05da23a-6dfe-4c1a-acfa-45fd85cc95b8`.

## 04 수정

- 설계 구간 7.60–11.60초와 독립 전사 발화 7.71–11.18초를 설명·그림 03 alt·수정 요청 예에서 구별했다.
- 다음 대사의 큐 시작 16.42초와 발화 관찰 시작 16.47초를 따로 표시했다.
- 일부 실제 모델 출력의 원본 시작 필드가 큐 시각을 사용한 한계를 명시했다. 42회 일치는 판정 일치이며 시간 근거의 정확성과 완전성을 보장하지 않는다는 경계를 유지했다.
- 입력 예에 컨테이너 길이 31.208333초와 디코드 음성 길이 31.189초를 함께 기록했다.
- 개방 자막의 어절 중간 줄바꿈·영상 진행 막대 가림에 대한 모델 관찰, 실패로 판정하지 않은 근거, 실제 표시 재점검 필요를 설명했다. 원래 C07 출력의 권고/한계를 대조했고, 플레이어 조작부와 영상 안의 진행 막대를 혼동하지 않았다.
- 꼬리 구간 경고와 발화·큐 시각 혼용을 별도 단락으로 나눴다.

최종 응답 발췌:

> 공개 권고 유지. 남는 필수 문제 없음.

평가자는 C01/C07/C08의 r1·r2 실제 출력과 수정 문장을 대조했다. 마지막 권장 두 가지도 반영됐다고 확인했다. 표기·후행 공백 같은 선택 사항은 의미·렌더링에 영향이 없다고 평가했다.

세션: `local_9dd162f5-631c-47ca-bd39-c8f949f31f7e`.

## 검증과 발행 상태

검증 프롬프트 두 개는 수정 전과 바이트 단위로 같다. 원래 실행 결과·입력·도식은 변경하지 않았고 초판 공개일과 기존 승인 기록을 보존했다. 변경 이력은 이 내부 보고서와 diff에만 남겼다.

Svelte 진단은 오류 0·경고 0이다. 04편 HTML 검토본도 갱신했고 1440/390/320px에서 도식 4개 로드·대체 텍스트·체크리스트 12개와 페이지 넘침 없음을 확인했다.

전체 콘텐츠 검사는 아직 통과하지 않는다. 03편이 공개된 이전 본문에서 변경돼 이전 승인 해시와 세 언어 번역의 원문 해시가 현재 한국어 정본과 다르기 때문이다. 같은 이유로 기존 공개 3편을 전제한 테스트 5개가 실패했고 18개는 통과했다. 검사를 우회하거나 승인값을 임의로 갱신하지 않았다. 이는 배포 가능한 네 언어 승인 패키지가 완성됐다는 뜻이 아니다.

이번 요청의 수정·편집 재평가는 완료했다. 번역, 새 공개 승인, 배포, 커밋·푸시, Telegram 전송은 수행하지 않았다. PDF는 이번에 재생성하지 않았으므로 기존 PDF는 이번 수정본이 아니다. 운영 링크·영상 재생과 추가 프롬프트 실행을 새로 확인하지 않았고 Desktop 서버 모델 ID는 독립 확인하지 못했다.

변경본의 sourceHash와 입력 해시, 실제 설정·세션·최종 판정·검증 제한은 `execution-receipt.json`과 `input-manifest.json`에 보관한다.
