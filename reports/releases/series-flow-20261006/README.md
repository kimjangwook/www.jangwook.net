# 시리즈 01–03 본문 흐름과 마무리 통일

## 평가와 변경

- 01: 본문 끝의 다음 글 예고가 링크 없는 한 문단이었다. 프롬프트 사용 안내와 02 형식의 마무리를 추가하고, 전체 학습 순서·다음 글을 연결했다. 첫 글에 없는 이전 글은 만들지 않았다.
- 02: 설명·실제 평가 결과 → 체크리스트 → 프롬프트 사용 안내 → 다음 글로 이어가기 → 참고 자료 → 복사 가능한 프롬프트 순서를 기준으로 삼았다. 이미 공개된 03 링크의 정적 준비 문구를 제거했다.
- 03: 체크리스트와 사용 안내 뒤에 있던 실습 결과를 설명 다음으로 옮겼다. iframe 두 개와 모든 실제 결과·범위 설명은 보존했다. 프롬프트 사용 설명은 한 절로 합치고, 프롬프트 패널을 02와 같은 본문 뒤 위치로 맞췄다. 마무리를 이전·전체 학습 순서·다음 링크로 통일했다.
- ko/en/ja/zh 12개 본문에 같은 원칙을 적용했다. 정적 준비 상태 표현은 본문에서 제거하며, 미공개 85편의 실제 준비 안내·noindex와 동적 목록 상태는 유지한다.
- 기존 URL과 초판 공개일을 유지하며 검증된 12개 프롬프트 파일은 바이트 단위로 보존한다. 이번 변경은 편집·배열 수정이며 새 모델 평가 실행이나 결과를 만들지 않았다.
