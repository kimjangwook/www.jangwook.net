# 평가 계획: 접근성 시리즈 '비텍스트 콘텐츠' 글의 시간 기반 매체 범위

이 문서는 평가 계획이다. 접근성 판정은 하지 않았다. 입력에 들어 있던 수집 기록(PAGE-K17)만 읽었고, 이 작업에서 페이지를 방문하거나 재생·키보드·화면 낭독기 조작을 하지 않았다. 이 사례에는 지정된 이미지가 없어 열어 본 화면 자료도 없다.

## 제공된 사실, 가정, 미확인 사항

| 구분 | 내용 |
|---|---|
| 제공된 사실 | 대상은 `https://jangwook.net/series/accessibility/non-text-content`의 본문 초기 상태(PAGE-K17). 수집 방법은 실제 운영 페이지의 Chromium DOM 스냅숏, main prose 범위, 광고 iframe 제외로 기록됨. |
| 제공된 사실 | 수집 집계: audio 0, video 0, 시간 기반 임베드 0, 애니메이션 이미지 후보 0, 정적 SVG 도식 있음. media_links·items·원본 관찰·대안·오류는 모두 비어 있음. 범위 안 목록이 완전하다고 기록됨. |
| 평가자 가정 | 집계 수치는 수집 시점(2026-10-04T12:04:54Z)의 main prose 범위에만 해당한다고 본다. |
| 미확인 | DOM 스냅숏 원문과 페이지 화면(이번 입력에 없음), 광고 iframe 내부 내용, 수집 이후 페이지 변경 여부, 정적 SVG 도식의 개수와 대체 텍스트, 브라우저 버전·뷰포트·확대 배율·보조 기술. |
| 미확인 | WCAG 2.2 각 기준 원문과 Understanding 문서(이 작업에서는 열람하지 않음). 아래 적용 조건은 '원문 확인 필요'를 전제로 한다. |

## A. 평가 범위

- **선택한 이용 과정**: 시리즈 글 본문을 읽으며 학습 자료의 조건·절차·경고·완료 결과를 이해한다. 첫 질문은 이 본문에 1.2.1 대상(사전 제작 음성 전용·영상 전용 콘텐츠)이 있는지, 있다면 대안이 동등한지다.
- **시작 조건**: 글 페이지 초기 상태 진입.
- **완료 조건**: 본문 범위의 시간 기반 매체 목록이 증거로 확정되고, 대상이 있으면 원본·대안 비교 증거가, 없으면 '대상 없음'을 뒷받침하는 목록 증거가 모인 상태.
- **포함 범위**: main prose 본문 영역의 audio·video·임베드·애니메이션 이미지·연속 이미지 후보, 정적 도식(후속 기준 후보로만).
- **제외 범위**: 광고 iframe(수집에서 제외됨), 사이트 공통 내비게이션, 다른 시리즈 글, 외부 계정.
- **목표 버전·수준**: WCAG 2.2, A와 AA(AA 목표는 A 기준을 함께 포함). 4.1.1 Parsing은 넣지 않는다.
- **미정인 실행 환경**: 브라우저 버전, 화면 크기, 확대 배율, 입력 방식, 보조 기술 모두 미정.
- **전체 사이트 평가와의 차이**: 한 글의 본문 범위만 다룬다. 광고 iframe과 다른 페이지가 빠져 있으므로 이 계획의 결과를 사이트 전체의 1.2.1 상태로 확대하지 않는다.

이 표의 기준은 규칙 검사·의미 평가·실제 조작으로 고정 분류한 것이 아니다. 예를 들어 1.2.1도 목록 확인 단계에서는 DOM 검사가, 대상이 생기면 원본과 대안의 의미 대조가 필요하다.

## C. 권장 실행 순서

1. **목록 재현(S01)**: DOM 스냅숏 원문을 받아 시간 기반 매체 후보를 다시 세고 PAGE-K17 집계와 맞춘다. 현재 권한으로는 원문을 받을 수 없으므로 실행 제안이다.
2. **상태 확장(S02)**: 스크롤·지연 로드 후 DOM을 같은 방법으로 수집해 초기 상태와 비교한다. 실행 제안이다.
3. **분기**: 대상이 없으면 1.2.1 결과를 '해당 없음'으로 기록하되 근거 증거 ID와 범위(main prose, 광고 제외, 수집 시각)를 함께 남긴다. 대상이 생기면 원본 전체 관찰(전사·프레임 그룹)과 대안을 수집해 정보 단위 대조로 넘어간다.
4. **후속 기준(S04·S05)**: 정적 SVG 도식은 1.1.1 평가 계획으로 분리해 도식별 DOM·접근성 트리·이미지를 수집한다.
5. **재평가**: 글이 갱신되면 같은 URL·같은 범위 정의로 1~3단계를 반복하고 수집 시각을 갱신한다.

## D. AI 평가 검증 계획

- **사례 구성**: 정상 사례(동등한 대안이 있는 음성 전용·영상 전용), 문제 사례(부정어 반전, 단계 누락, 대안 없음), 경계 사례(대상이 전혀 없는 페이지, 광고 iframe에만 매체가 있는 페이지, 지연 로드로만 나타나는 매체, 디코딩 실패 원본, 일부 구간만 관찰 가능한 원본, 기존 텍스트 예외 주장)를 둔다. 이 페이지는 '대상 없음' 경계 사례의 실제 예가 될 수 있다.
- **기준 답 검토 절차**: 각 사례의 기준 답에 목록 증거와 원본·대안 위치를 붙이고, 작성자가 아닌 검토자가 WCAG 원문과 대조해 확정한다.
- **결과 분류**: 오탐, 누락, 판단 유보를 판정 오류 유형으로, 수집 실패·입력 누락을 실행 실패로 나눠 기록한다. 대상이 없는 페이지에서 모델이 가상의 매체나 시간 코드를 만들어 내는지도 오탐 항목으로 확인한다.
- **반복 일관성**: 같은 입력을 같은 설정으로 반복 실행해 판정과 근거가 유지되는지 기록한다. 반복 횟수는 실행 전에 정한다.
- **재현 노력 기록**: 사례별 수집 시간, 필요한 도구·권한, 사람이 확인한 단계 수를 남긴다.
- 측정 전이므로 정확도·비용·평가 완료를 주장하지 않는다.

## E. 후속 결과 기록 양식

| 상태·환경 | 기준·검사 질문 | 실행 상태 | 판정 | 증거 ID와 위치 | 사용자 영향 | 가정·반대 증거 | 수정 제안 | 재평가 조건 |
|---|---|---|---|---|---|---|---|---|
| 예: S01 / Chromium 버전 미정 / 기본 배율 | 1.2.1 / main prose 범위에 사전 제작 음성 전용·영상 전용 콘텐츠가 있는가 | 미실행 | 미평가 | (실행 후 기입) | (실행 후 기입) | (실행 후 기입) | (실행 후 기입) | 같은 URL·범위·수집 방법 |

- 실행 상태: 미실행 / 실행됨 / 실패 / 차단
- 판정: 미평가 / 충족 / 미충족 / 해당 없음 / 판단 유보
- '미평가'는 판정을 시도하지 않은 상태이고, '판단 유보'는 평가를 시도했지만 증거나 해석이 부족한 상태다.
- '해당 없음'에는 적용하지 않는 이유(예: 범위 안 대상 없음)와 그 근거 증거 ID, 범위 제한(광고 iframe 제외 등)을 반드시 적는다.

## F. 바로 준비할 자료(우선순위)

1. PAGE-K17의 DOM 스냅숏 원문. 집계 수치를 재현해 '대상 없음' 근거를 확정한다.
2. 스크롤 후·지연 로드 후 상태의 DOM. 초기 상태만으로 놓칠 수 있는 매체를 확인한다.
3. 범위 결정: 광고 iframe을 평가 범위에 넣을지 여부.
4. 정적 SVG 도식 목록과 각 도식의 alt·접근성 이름(1.1.1 후속 계획용).
5. 평가 환경 확정: 브라우저 버전, 뷰포트, 확대 배율, 보조 기술.
6. 확인할 질문: 이 글에 이후 영상이나 음성을 추가할 계획이 있는가? 있다면 원본 파일과 대안을 함께 준비할 수 있는가?

자료를 넘길 때는 로그인 세션, 쿠키, 개인정보가 DOM이나 네트워크 기록에 포함되지 않았는지 먼저 확인하고 제거한다.
