# P-NONE 평가 계획: 접근성 시리즈 이전 글(비텍스트 콘텐츠)의 시간 기반 매체 확인

이 문서는 평가 계획입니다. 접근성 판정(충족·미충족·해당 없음 등)은 내리지 않았습니다. 제공된 텍스트 기록만 읽었고, 이 사례에 지정된 이미지는 없습니다. URL을 방문하지 않았고 재생·키보드·화면 낭독기 조작도 하지 않았습니다.

## A. 평가 범위

- **선택한 이용 과정**: 이용자가 접근성 시리즈의 이전 글 본문을 읽으며 학습 자료의 조건·절차·경고·결과를 이해하는 읽기 과정. 1.2.1 관점에서는 이 과정에 사전 제작 음성 전용·영상 전용 콘텐츠가 있는지, 있다면 대안이 있는지가 첫 질문입니다.
- **시작 조건**: 글 페이지의 초기 문서 상태(PAGE-K17).
- **완료 조건(이번 작업)**: 1.2.1 대상 목록을 확정하기 위한 범위와 증거 수집 계획을 정함. 원본·대안 비교는 대상이 확인될 때만 계획에 추가합니다.
- **포함**: main prose의 초기 상태, 그 안의 미디어·임베드·애니메이션 후보, 정적 SVG 도식(1.2.1 대상 여부 확인용).
- **제외(입력에 명시됨)**: 플레이어 키보드 조작, 자막, 1.2.1 이외의 기준(후보로만 구분), 외부·실제 사용자 계정. 수집 방법에서 광고 iframe이 제외됨.
- **목표 버전·수준**: WCAG 2.2, A·AA(AA는 A를 포함). 첫 질문은 1.2.1(A). 4.1.1 Parsing은 넣지 않습니다.
- **미정인 실행 환경**: 브라우저 종류·버전(수집기는 Chromium으로만 기록), 화면 크기, 확대 배율, 입력 방식, 보조 기술.
- **전체 사이트 평가와의 차이**: 이 계획은 글 한 편의 main prose 초기 상태만 다룹니다. 목록에서 대상이 0개로 기록됐더라도, 그 사실을 페이지 전체(내비게이션, 광고 영역)나 다른 글, 사이트 전체에 대상이 없다는 주장으로 넓히지 않습니다.

## C. 권장 실행 순서

현재 권한은 제공 자료 열람뿐이므로 수집이 필요한 단계는 실행 제안으로만 남깁니다.

1. **상태 복원(제안)**: 같은 URL을 같은 시점의 판본으로 열 수 있는지 확인하고 브라우저·뷰포트·확대·입력 방식을 기록합니다. 운영 페이지이므로 폼 제출이나 계정 조작은 하지 않습니다.
2. **자료 수집(제안)**: S0의 DOM 스냅숏 원본과 목록 수집 규칙, S1의 SVG 마크업, S3의 상호작용 영역 목록을 수집합니다.
3. **규칙 검사**: DOM에서 미디어 요소와 임베드를 다시 셉니다. 이 단계는 목록 확인 질문이며, 의미 판단과 같은 단계로 묶지 않습니다.
4. **의미 확인**: 애니메이션 후보나 연속 이미지가 있다면 그것이 정보를 전달하는 시간 기반 콘텐츠인지 판단할 자료(캡처, 프레임)를 따로 모읍니다.
5. **목록 결과 기록**: 대상이 확인되지 않으면 그 근거(수집 범위, 규칙, 상태)를 남겨 해당 없음 판정의 근거로 씁니다. 대상이 확인되면 S4로 넘어갑니다.
6. **검토와 재평가**: 글이 갱신되면 같은 범위와 규칙으로 목록을 다시 수집합니다.

## D. AI 평가 검증 계획

측정 전이므로 정확도, 비용, 평가 완료를 주장하지 않습니다.

- **사례 구성**:
  - 정상(대상 없음): 미디어가 실제로 없는 글. 목록 근거가 갖춰진 상태.
  - 문제: 지연 로딩되는 동영상 임베드나 자동 재생 애니메이션이 있는데 초기 목록에 빠진 글.
  - 경계: 정적 SVG와 애니메이션 SVG가 섞인 글, main prose 밖에만 미디어가 있는 글, 목록 수집 자체가 실패한 글.
- **기준 답 근거 검토**: 기준 답마다 DOM 위치와 수집 규칙을 함께 남기고, 사람이 DOM을 직접 확인해 대상 유무를 검토합니다. 범위 밖 대상은 "범위 밖"으로 따로 표시합니다.
- **결과 분류 기록**: 오탐(대상이 없는데 있다고 판단), 누락(대상이 있는데 없다고 판단해 해당 없음 처리), 판단 유보, 실행 실패(목록 수집 실패, 입력 미읽기, 출력 파싱 불가)를 나눠 기록합니다. 특히 "목록 미확인"을 "해당 없음"으로 바꾼 경우를 별도 오류 유형으로 셉니다.
- **반복 일관성**: 같은 입력으로 여러 번 실행해 판정과 근거가 같은지 기록합니다. 실행 횟수는 측정 계획에서 정합니다.
- **재현 노력**: 사람이 목록을 다시 확인하는 데 걸린 시간과 추가로 열어 본 자료를 기록합니다.

## E. 후속 결과 기록 양식

| 상태·환경 | 기준·검사 질문 | 실행 상태 | 판정 | 증거 ID와 위치 | 사용자 영향 | 가정·반대 증거 | 수정 제안 | 재평가 조건 |
|---|---|---|---|---|---|---|---|---|
| 예: S0, 초기 문서 main prose, 환경 미정 | 1.2.1 / 지정 범위에 사전 제작 음성 전용·영상 전용 대상이 있는가 | 미실행 | 미평가 | (수집 후 기재) | (판정 후 기재) | (기재) | (기재) | 같은 URL·판본·범위·수집 규칙 |

- **실행 상태**: 미실행 / 실행됨 / 실패 / 차단.
- **판정**: 미평가 / 충족 / 미충족 / 해당 없음 / 판단 유보.
- **미평가**는 판정을 시도하지 않은 상태이고, **판단 유보**는 평가를 시도했지만 증거나 해석이 부족한 상태입니다.
- **해당 없음**에는 적용하지 않는 이유를 구체적으로 적습니다. 예: "main prose 초기 상태에서 수집 규칙 X로 셌을 때 대상 0개".
- 위 예시 행은 양식 설명용이며 실제 결과가 아닙니다.

## F. 바로 준비할 자료 (우선순위순)

1. **S0 DOM 스냅숏 원본과 목록 수집 규칙**: 대상 0개라는 기록을 검증하기 위해 가장 먼저 필요합니다. 질문: iframe, 지연 로딩 요소, CSS 애니메이션은 어떻게 셌습니까?
2. **SVG 도식 목록과 마크업**: 정적인지 확인해 1.2.1 대상 여부를 정하고, 1.1.1 후보로 넘깁니다.
3. **상호작용으로 열리는 영역이 있는지 여부**: 초기 상태 밖의 미디어 가능성을 확인합니다.
4. **범위 결정**: main prose 밖과 광고 iframe을 계속 제외할지 정합니다.
5. **평가 환경 확정**: 브라우저 버전, 화면 크기, 확대, 입력 방식, 보조 기술.

자료를 제출할 때 개인정보와 인증 정보(로그인 쿠키, 계정 화면 등)가 들어가지 않도록 하십시오. 운영 페이지의 DOM을 수집할 때 로그인 상태 정보가 포함되면 제거한 뒤 제출해야 합니다.
