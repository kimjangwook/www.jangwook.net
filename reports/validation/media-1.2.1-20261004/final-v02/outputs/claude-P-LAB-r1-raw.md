# 평가 계획: 복구 코드 학습 실습 페이지의 무음 안내 영상과 대안

이 문서는 평가 계획이다. 접근성 판정은 하지 않았다. 아래의 "제공 자료"는 입력에 들어 있던 수집 기록과 이 작업에서 실제로 열어 본 PNG 5장을 뜻하며, 재생·키보드·화면 낭독기 조작은 수행하지 않았다.

## A. 평가 범위

- **선택한 이용 과정**: 학습 페이지에서 무음 안내 영상(M-V)과 그 텍스트 대안(ALT-V)을 읽거나 재생해, 복구 코드 생성의 전제 조건·절차·경고·완료 결과를 이해한다.
- **시작 조건**: 페이지 초기 상태(PAGE-K63)에 진입한다.
- **완료 조건**: 이용자가 영상 또는 대안만으로 다섯 단계의 조건·동작·경고·결과를 같은 순서로 알 수 있는지 판단할 증거가 모인 상태. 이번 산출물은 그 증거 수집 계획이다.
- **포함 범위**: M-V 원본 전체(0~19.916667초), ALT-V 전체, 둘의 연결 관계, 영상 플레이어와 대안 문단이 있는 본문 영역.
- **제외 범위**: 외부 계정·실제 복구 코드 생성, 폼 제출, 사이트 공통 내비게이션, 다른 페이지. 입력 기록이 제외한 "Player keyboard, captions and other WCAG criteria"는 이번 첫 질문(1.2.1)의 수집 범위에서 빠져 있을 뿐이며, B표에서 후속 후보로 따로 표시한다.
- **목표 버전·수준**: WCAG 2.2, A와 AA(AA 목표는 A 기준을 함께 포함). 4.1.1 Parsing은 WCAG 2.2에서 삭제되어 넣지 않는다. 첫 질문은 1.2.1이다.
- **미정인 실행 환경**: 브라우저 버전(수집 기록에는 Chromium만 있고 버전 없음), 화면 크기, 확대 배율, 입력 방식, 보조 기술 종류와 버전 모두 미정.
- **전체 사이트 평가와의 차이**: 이 계획은 한 페이지의 한 미디어와 그 대안만 다룬다. 결과를 시리즈 전체나 사이트 적합성으로 확대하지 않는다.

## C. 권장 실행 순서

1. **자료 고정**: MEDIA-V 해시, ALT-V 판본, FRAME-N과 observed-N 대조 결과를 같은 수집 회차로 묶는다. 현재 권한으로는 해시 대조 재실행이 불가하므로 실행 제안으로 남긴다.
2. **원본 정보 단위 작성(S02)**: 프레임 그룹마다 화면 문구·버튼·순서·상태 변화를 시간 구간과 함께 표로 만든다. 제공 자료로 지금 진행할 수 있는 단계다.
3. **대안 대조(S03)**: 2단계 표의 각 단위를 ALT-V 문단과 연결해 equivalent·missing·inaccurate·uncertain을 기록한다. 이 단계가 끝나면 1.2.1 판정을 시도할 수 있다.
4. **페이지 구조 수집(S01)**: DOM 원문과 접근성 트리를 받아 영상 요소 속성과 대안의 위치·연결을 확인한다. 현재 권한 밖이므로 실행 제안이다.
5. **조작 기록(S04~S06)**: 키보드 재생·정지, 초점 이동, 낭독기 출력을 기록한다. 조작이 허용되지 않은 현재 범위에서는 실행 제안으로만 남긴다.
6. **측정(S07~S08)**: 확대·리플로 캡처와 색상 대비 측정을 도구로 수행한다. 실행 제안이다.
7. **검토와 재평가**: 문제가 확인되면 수정 후 같은 해시·같은 판본·같은 환경에서 2~6단계를 다시 수행하고, 수정 전후 증거 ID를 나란히 기록한다.

## D. AI 평가 검증 계획

- **사례 구성**: 같은 원본(M-V)에 대해 대안만 바꾼 세트를 만든다.
  - 정상 사례: 모든 화면 정보를 담은 대안.
  - 문제 사례: 단계 누락, 부정어 반전, 순서 뒤바뀜, 대안 연결 없음.
  - 경계 사례: 표현만 다른 대안, 원본 일부 구간만 관찰 가능한 자료, 디코딩 실패 파일, 기존 텍스트 예외 주장(완전한 텍스트와 요약 텍스트 각각), 음성 대안만 있는 영상 전용.
- **기준 답 검토 절차**: 각 사례의 기준 답에 근거 문장(원본 위치와 대안 위치)을 붙이고, 작성자가 아닌 검토자가 WCAG 원문과 Understanding 문서를 대조해 확정한다. 이견은 해소 과정까지 기록한다.
- **결과 분류**: 판정 오류를 오탐(문제 없는데 실패), 누락(문제를 통과), 판단 유보(증거 부족을 이유로 보류)로 나누고, 도구 실패·입력 누락 같은 실행 실패는 판정과 별도 열로 기록한다. 판단 유보가 정당했는지도 따로 검토한다.
- **반복 일관성**: 같은 입력을 같은 프롬프트·모델 설정으로 여러 번 실행해 판정과 근거 위치가 바뀌는지 기록한다. 실행 횟수와 설정은 실행 전에 정한다.
- **재현 노력 기록**: 자료 수집 시간, 사람이 확인한 단계 수, 재실행에 필요한 도구와 권한을 사례별로 남긴다.
- 아직 측정하지 않았으므로 정확도·비용·평가 완료를 주장하지 않는다.

## E. 후속 결과 기록 양식

| 상태·환경 | 기준·검사 질문 | 실행 상태 | 판정 | 증거 ID와 위치 | 사용자 영향 | 가정·반대 증거 | 수정 제안 | 재평가 조건 |
|---|---|---|---|---|---|---|---|---|
| 예: S03 / Chromium 버전 미정 / 기본 배율 | 1.2.1 / ALT-V가 M-V의 각 화면 정보를 같은 의미로 전달하는가 | 미실행 | 미평가 | (실행 후 기입) | (실행 후 기입) | (실행 후 기입) | (실행 후 기입) | 같은 해시·판본·환경 |

- 실행 상태: 미실행 / 실행됨 / 실패 / 차단
- 판정: 미평가 / 충족 / 미충족 / 해당 없음 / 판단 유보
- '미평가'는 판정을 시도하지 않은 상태이고, '판단 유보'는 평가를 시도했지만 증거나 해석이 부족한 상태다.
- '해당 없음'에는 적용하지 않는 이유와 그 근거 증거 ID를 반드시 적는다.

## F. 바로 준비할 자료(우선순위)

1. PAGE-K63의 DOM 원문(video 요소 속성, 대안 문단의 위치와 연결 방식, 제목 구조). 1.2.1 연결 관계와 S01·S05 판단의 기초다.
2. FRAME-1~5와 OBS-V의 observed-1~5 이미지 해시 대조 기록. 원본 관찰 자료의 동일성을 확정한다.
3. 평가 환경 확정: 브라우저 버전, 뷰포트, 확대 배율, 입력 방식, 보조 기술과 버전.
4. 조작 허용 범위 결정: 재생·키보드·낭독기 조작을 허용할지, 누가 수행할지.
5. 확인할 질문: 이 페이지의 목표 수준을 A로 할지 AA로 할지 최종 확정했는가? 영상이 자동 재생되는가? 대안 문단을 영상의 대안으로 안내하는 문구가 있는가?

자료를 넘길 때는 실제 계정 정보, 실제 복구 코드, 개인정보, 인증 토큰이 화면이나 로그에 들어 있지 않은지 먼저 확인하고 제거한다.
