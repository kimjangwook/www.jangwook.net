# 평가 계획: 접근성 시리즈 이전 글(non-text-content)의 미디어 유무 확인과 대안 비교

이 문서는 평가 계획입니다. 접근성 판정은 내리지 않았고, 아래의 모든 기준은 '미평가' 상태입니다.

## 입력 정리: 사실·가정·미확인

| 구분 | 내용 | 근거 |
|---|---|---|
| 제공된 사실 | 대상은 `https://jangwook.net/series/accessibility/non-text-content`의 이전에 게시된 글 본문, 초기 상태다 | 입력 자료 |
| 제공된 사실 | 운영 페이지를 Chromium으로 연 DOM 스냅숏에서 main prose 범위만 수집했고, 광고 iframe은 제외했다 | PAGE-K17 collection_method |
| 제공된 사실 | 수집기가 센 값은 audio 0, video 0, 시간 기반 임베드 0, 애니메이션 이미지 후보 0이다. 정적 SVG 도식은 있다(static_svg_diagrams=true) | PAGE-K17 observed |
| 제공된 사실 | 미디어-대안 연결(media_links), 원본 관찰 기록, 대안 기록, 오류 기록은 모두 빈 배열이다. 이 범위의 목록 수집은 완료로 기록돼 있다 | PAGE-K17, 자료별 식별자 |
| 제공된 사실 | 재생, 키보드 조작, 화면 낭독기 조작은 수행되지 않았다. 이번 작업에서 추가 수집과 URL 방문은 하지 않았다 | 알려진 상태, 연결된 도구와 권한 |
| 가정 | 평가 목표는 WCAG 2.2 AA(A와 AA 포함)로 둔다. 입력의 'A·AA'를 AA 목표로 해석했다 | 입력 '목표 기준과 수준' |
| 가정 | 이용자는 글 본문과 도식을 읽어 학습 내용을 이해하면 과제를 끝낸다 | 입력 '이용자가 하려는 일' |
| 미확인 | DOM 원문, 정적 SVG 도식의 개수·위치·대체 텍스트 | 미정 |
| 미확인 | main prose 밖(머리글, 사이드바, 바닥글, 광고 iframe)과 초기 상태 이후(지연 로드, 스크롤, 상호작용 후)의 미디어 유무 | 미정 |
| 미확인 | 브라우저 버전, 화면 크기, 확대 설정, 입력 방식, 보조 기술 | 미정 |

입력의 '서비스 설명'과 '이용자가 하려는 일'은 복구 코드 실습 페이지도 가리킬 수 있게 쓰여 있습니다. 그러나 대상 URL과 제공 자료는 non-text-content 글 하나뿐이므로, 이 계획은 그 글만 다룹니다. 복구 코드 실습 페이지는 이 계획에 포함하지 않았습니다.

## A. 평가 범위

- 선택한 이용 과정: non-text-content 글을 처음 열어 본문과 도식을 읽고, 글에 사전 제작 음성·영상이 있다면 그 대안을 이용하는 과정
- 시작 조건: 글을 처음 연 초기 상태
- 완료 조건: 본문 범위의 시간 기반 미디어 유무가 증거로 확정되고, 미디어가 있다면 원본·대안 비교 계획이, 없다면 1.2.1을 '해당 없음'으로 기록할 근거가 갖춰진 상태
- 포함 범위: main prose 영역의 초기 상태, 그 안의 정적 SVG 도식(1.2.1의 후보가 아님을 확인하는 대상이자 1.1.1의 후보)
- 제외 범위: 수집 기록의 제외 항목(플레이어 키보드·자막·다른 기준은 수집 단계에서 제외됨), 외부 또는 실제 사용자 계정, 광고 iframe, 폼 제출
- 목표 버전·수준: WCAG 2.2, AA(가정). 첫 질문은 1.2.1, 나머지는 후보로 구분
- 미정인 실행 환경: 브라우저와 버전, 뷰포트 크기, 확대 배율, 키보드·포인터 입력, 화면 낭독기 종류와 버전
- 전체 사이트 평가와의 차이: 이 계획은 한 글의 본문 영역과 초기 상태만 다룹니다. 이 글에 미디어가 없다는 결과가 나오더라도 시리즈의 다른 글이나 사이트 전체에 미디어가 없다는 뜻이 아니며, 사이트 단위 적합성은 판단하지 않습니다.

## C. 권장 실행 순서

현재 권한은 제공된 텍스트 열람뿐입니다. 아래의 수집·조작 단계는 모두 실행 제안입니다.

1. 범위 확정: 평가 범위를 main prose 초기 상태로 둘지, 스크롤 후 상태와 본문 밖 영역까지 넓힐지 결정합니다.
2. 자료 수집(실행 제안): 같은 URL과 같은 판본에서 DOM 원문과 미디어 집계 근거(선택자, 일치 요소 목록)를 수집하고, 스크롤 후 상태도 한 번 더 수집합니다.
3. 목록 확정: 집계 근거로 시간 기반 미디어 유무를 확정합니다. 정적 SVG는 1.2.1 대상이 아니라는 근거(움직임·시간 축이 없음)를 기록합니다. 애니메이션 SVG나 CSS 애니메이션이 있는지도 함께 봅니다.
4. 분기:
   - 미디어가 없으면 1.2.1을 '해당 없음'으로 기록하되, 이유와 확인한 범위·상태를 함께 적습니다.
   - 미디어가 있으면 B의 S4 계획에 따라 원본 전체 구간 관찰과 대안 비교를 수행합니다.
5. 후보 기준 검토(실행 제안): S1의 정적 도식에 대해 1.1.1 평가를 별도로 수행합니다. 대체 텍스트의 존재 같은 규칙 검사와, 대체 텍스트가 도식의 목적을 전달하는지 같은 의미 평가를 같은 기준 안에서 구분해 기록합니다.
6. 조작 기록(실행 제안): 키보드와 화면 낭독기로 도식과 본문을 탐색하고 출력 원문을 기록합니다. 스크린샷만으로 낭독 출력이나 초점 이동을 확정하지 않습니다.
7. 수정 후 재평가: 글이 개정되면 같은 범위·상태에서 2~4단계를 반복합니다.

## D. AI 평가 검증 계획

측정 전이므로 정확도, 비용, 평가 완료를 주장하지 않습니다.

- 사례 구성:
  - 정상 사례: 미디어가 없고 집계 근거가 완전한 페이지(해당 없음이 기대됨)
  - 문제 사례: 미디어가 있는데 대안이 없거나 불완전한 페이지
  - 경계 사례: 정적 SVG만 있는 페이지, 애니메이션 GIF나 애니메이션 SVG가 있는 페이지, 초기 상태에는 없고 스크롤 후 삽입되는 미디어, 수집 범위가 본문으로 제한된 페이지, 집계 값만 있고 DOM 원문이 없는 페이지
- 기준 답의 근거 검토: 사례마다 DOM 원문과 집계 근거를 보관하고, 평가자 두 명 이상이 1.2.1 원문과 Understanding 문서를 근거로 '해당 없음'과 '판단 유보'의 경계를 따로 판단한 뒤 차이를 합의 기록으로 남깁니다.
- 결과 분류: 오탐(미디어가 없는데 미충족), 누락(미디어가 있는데 해당 없음), 판단 유보(범위 제한으로 확정 불가), 실행 실패(자료를 읽지 못함·출력 형식 오류)를 따로 셉니다. 특히 '대상 없음'을 사이트 전체로 넓혀 말하는 과잉 일반화를 별도 항목으로 기록합니다.
- 반복 일관성: 같은 입력을 같은 모델·설정으로 여러 번 실행해 판정과 범위 설명이 바뀌는지 기록합니다.
- 재현 노력 기록: 수집에 쓴 도구와 버전, 수집 시각, 재실행에 필요한 파일과 해시, 사람이 확인해야 했던 지점을 적습니다.

- 실행 상태: '미실행'은 시도하지 않음, '실행됨'은 수집·검사를 마침, '실패'는 도구 오류 등으로 끝내지 못함, '차단'은 권한·환경 때문에 시작하지 못함입니다.
- 판정: '미평가'는 판정하지 않은 상태이고, '판단 유보'는 평가를 시도했지만 증거나 해석이 부족한 상태입니다. '해당 없음'에는 적용하지 않는 이유와 확인한 범위를 반드시 적습니다.
- 위 예시 행은 양식 설명이며 실제 결과가 아닙니다.

## F. 바로 준비할 자료

우선순위 순입니다.

1. 범위 결정: main prose 초기 상태만 평가할지, 스크롤 후 상태와 본문 밖 영역(광고 iframe 포함 여부)까지 넓힐지 알려 주세요. 1.2.1의 '해당 없음'이 어디까지 유효한지가 이 결정에 달려 있습니다.
2. DOM 원문 또는 미디어 집계 근거: 현재는 audio 0, video 0 같은 집계 값만 있어, 어떤 선택자로 무엇을 셌는지 확인할 수 없습니다.
3. 정적 SVG 도식 목록과 각 도식의 대체 텍스트·주변 문맥: 후보 기준 1.1.1 평가에 필요합니다.
4. 평가 환경 결정: 브라우저와 버전, 뷰포트, 확대 배율, 화면 낭독기 종류와 버전을 정해 주세요.
5. 목표 수준 확인: 'A·AA'를 AA 목표로 해석했습니다. A만 확인하려는 것이라면 알려 주세요.
6. 대상 확인: 입력의 서비스 설명에 '복구 코드 학습 실습 페이지'도 언급돼 있습니다. 그 페이지도 평가하려면 별도의 URL과 자료가 필요합니다.

자료를 제출할 때는 개인정보, 실제 계정 정보, 인증 정보를 넣지 마세요.
