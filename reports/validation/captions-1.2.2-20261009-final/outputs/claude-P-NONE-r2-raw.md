## C. 권장 실행 순서

현재 권한은 "제공 자료 읽기"뿐이므로 수집·조작 단계는 **실행 제안**입니다.

1. **상태 복원 준비**: 같은 URL을 같은 브라우저·버전·뷰포트·확대율로 열 수 있도록 환경을 고정해 기록합니다. 공개 사이트이므로 로그인·댓글·제출은 하지 않습니다.
2. **범위 확정**: 상위 scope의 'this one teaching video' 문구와 빈 매체 목록의 불일치를 의뢰자에게 확인합니다(F-1).
3. **자료 수집(제안)**: 전체 HTML·접근성 트리·초기 스크린샷(S0) → 본문 끝까지 스크롤한 뒤 DOM 재수집(지연 로드 매체 확인, S3) → 키보드 순회 기록(S2) → 이미지·색·애니메이션 캡처(S1, 기타). 각 자료에 ID·수집 시각·상태 ID를 붙입니다.
4. **규칙 검사**: `<title>`, `lang`, 이미지 alt 속성 존재, 헤딩 계층, 링크 이름 존재를 자동 검사합니다. 속성 존재는 적절성의 증명이 아닙니다.
5. **의미 평가**: alt 문구의 적절성, 링크 목적의 맥락 명확성, 구조가 시각 표현과 일치하는지 판단합니다.
6. **조작 기록 확인**: 초점 순서·함정·맥락 변경을 키보드 기록으로 확인합니다.
7. **검토와 재평가**: E 양식으로 기록하고, 수정 후 같은 환경에서 영향 상태 전체를 다시 수집합니다.

## D. AI 평가 검증 계획

- **사례 구성**: (1) 정상 사례: 매체가 실제로 없는 기사(현재 대상과 같은 유형), (2) 문제 사례: 같은 기사에 자막 없는 영상, alt 없는 정보 이미지, 키보드로 닿지 않는 링크를 각각 하나씩 넣은 변형, (3) 경계 사례: 범위 밖 외부 임베드에만 영상이 있는 경우, 지연 로드로 DOM 첫 수집에 빠진 영상, 범위 문구와 목록이 어긋나는 경우(현재 입력과 같음).
- **기준 답 검토**: 기준 답은 실제 DOM·조작 기록과 WCAG 원문(원문 확인 필요)에 근거해 적고, 평가 대상 모델과 독립된 검토자가 확인합니다. 해석이 갈리는 경계 사례는 근거와 함께 별도 표시합니다.
- **결과 분류**: 오탐, 누락, 판단 유보의 적절성, 실행 실패(수집 실패·차단)를 구분하고, 실행 실패를 '해당 없음'으로 바꾸지 않았는지 확인합니다. 특히 매체 없음 판정이 '목록 불완전'을 숨기지 않았는지 점검합니다.
- **반복 일관성**: 같은 입력을 같은 조건으로 반복 실행해 판정과 인용 증거가 일치하는지 기록하고, 독립 세션인지 같은 세션 배치인지 명시합니다.
- **재현 노력 기록**: 사례별 소요 시간, 읽은 자료 수, 도구 호출, 사람 개입 횟수를 남깁니다.
- 측정 전에는 정확도·비용·평가 완료를 주장하지 않습니다.

## F. 바로 준비할 자료(우선순위)

1. 질문: 상위 scope의 "this one teaching video"는 이 기사에 실제 영상이 있다는 뜻입니까, 아니면 다른 사례에서 옮겨 온 문구입니까?
2. 기사 전체 HTML과 접근성 트리(본문 끝까지 스크롤한 뒤 수집), `<title>`·`lang` 포함.
3. 초기 로드 스크린샷과 팝업·배너 유무.
4. 키보드만으로 본문 링크·컨트롤을 순회한 기록(초점 위치 포함).
5. 본문 이미지 목록과 각 alt, 색·애니메이션 요소 캡처.
6. 테스트 환경 정보: 브라우저 버전, OS, 뷰포트, 확대율, 보조 기술 사용 여부.

자료에 로그인 세션 쿠키, 계정 정보, 개인 연락처 등 개인정보·인증 정보가 들어가지 않도록 제거한 뒤 제공해 주십시오.
