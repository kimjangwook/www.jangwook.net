# P-LAB 평가 계획 (WCAG 2.2 수준 A, 복구 코드 안내 영상 페이지)

이 문서는 평가 계획이며 접근성 판정이 아닙니다. 평가자(Claude Opus 5.5)는 이 조건에서 P-LAB.txt에 담긴 텍스트 자료만 읽었습니다. URL 방문, 재생, 키보드 조작, 화면 낭독기 사용은 하지 않았습니다. 자료 안의 `DISPLAY-C01-1~3` 이미지는 ID로만 언급되어 있고 이 조건에는 첨부되지 않았으므로 관찰 자료로 쓰지 않았습니다.

## C. 권장 실행 순서

1. **상태 복원**: 동일 URL·Chromium 버전·창 크기·확대 100%·자막 기본값을 기록하고 S0을 재현합니다. (도구 없음 → 실행 제안)
2. **자료 수집**: S0의 DOM·head·접근성 트리, S1의 키보드 조작 로그와 초점 캡처, S2의 각 큐 활성 시점 화면과 장면별 카드 문구, S3·S4의 상태 전이 기록. 화면 낭독기(예: NVDA·VoiceOver) 출력 로그는 사용 도구와 버전을 함께 기록합니다. (실행 제안)
3. **규칙 검사**: title·lang·조작부 이름·track 속성 등 속성 수준 질문을 먼저 확인합니다.
4. **의미 평가**: 원본 전사(SOURCE-ASR)와 자막 큐를 정보 단위로 나눠 부정·조건·화자·경고음 의미를 대조하고, 화면 카드 문구와 음성의 차이를 1.2.3 관점에서 정리합니다. 후보 자막을 원본 증거로 재사용하지 않습니다.
5. **조작 기록 확인**: 키보드 전용 재생·자막 전환이 실제로 되었는지 로그와 트리로 확인합니다. 스크린샷만으로 초점·낭독 결과를 확정하지 않습니다.
6. **검토**: 판정마다 증거 ID와 반대 증거를 붙이고 판단 유보 사유를 기록합니다.
7. **수정 후 재평가**: 수정이 있으면 영향을 받는 상태만 다시 수집해 같은 양식으로 재평가합니다.

## D. AI 평가 검증 계획

- **사례 구성**: 같은 원본 영상에 대해 (1) 정상 자막, (2) 부정 반전·경고음 누락·화자 표기 제거·시간 이동·트랙 없음 같은 단일 결함 변형, (3) 의미 유지 의역·개방 자막·검증된 매체 대안·일부 구간만 처리된 증거·로드 실패 같은 경계 사례를 만듭니다. 각 사례는 결함 하나만 바꿔 원인을 분리합니다.
- **기준 답 근거 검토**: 사례별 기대 판정의 근거(어떤 원본 단위가 어떤 큐와 어떻게 다른지)를 문서화하고, 평가 모델과 독립된 검토자 2인 이상이 WCAG 이해 문서와 대조해 합의합니다. 해석이 갈리는 사례(예: 문맥상 화자 추론 가능성)는 경계 사례로 따로 표시합니다.
- **오류 분류**: 오탐(결함 없는데 미충족), 누락(결함 있는데 충족), 판단 유보(증거 부족을 정확히 지적했는지), 실행 실패(도구·입력 오류를 판정으로 바꾸지 않았는지)를 별도 집계합니다.
- **반복 일관성**: 같은 입력을 동일 설정으로 여러 번 실행해 판정·핵심 근거의 일치율을 기록하고, 입력 순서나 문구를 바꾼 변형에서도 비교합니다.
- **재현 비용 기록**: 실행마다 모델·노력 수준·읽은 파일과 해시·소요 시간·토큰 또는 비용 추정·사람 검토 시간을 남깁니다.
- 측정 전에는 정확도·비용·완료를 주장하지 않습니다.

## F. 바로 준비할 자료 (우선순위)

1. **환경 정보**: Chromium 버전, OS, 확대·글꼴 설정, 사용할 화면 낭독기와 버전 — 현재 미정.
2. **S0 DOM 전체**: `<head>`의 title과 `<html lang>` 포함. 현재 본문 텍스트만 있음.
3. **키보드 전용 조작 기록(S1·S3)**: 재생·정지·자막 메뉴·전체 화면을 키보드로 조작한 순서와 초점 캡처, 접근성 트리의 조작부 이름·역할.
4. **S2 표시 화면**: DISPLAY-C01-1~3 PNG를 이 평가 조건에 실제로 첨부하거나 동일 시점 화면을 다시 수집.
5. **시각 정보 목록**: 7개 장면 카드의 제목·안내문·버튼 문구 전문(1.2.3 판단용).
6. **자동 재생·번쩍임 여부**: 페이지 로드 시 재생 시작 여부와 소리 출력 시간, 번쩍임 측정 결과.
7. **질문**: 하단 내비게이션 외에 반복 블록이 범위 안에 있는지, 오디오 설명 트랙이나 별도 대체 텍스트가 있는지.

수집 자료에 실제 계정 정보·개인정보·인증 정보가 들어가지 않도록 하고, 들어간 자료는 제출하지 마세요. 이 페이지는 교육용이며 실제 코드를 입력하지 않는다고 명시되어 있으므로 입력 테스트도 하지 않습니다.
