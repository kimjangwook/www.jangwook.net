# P-NONE 평가 계획 (WCAG 2.2 수준 A, 접근성 개요 기사 읽기)

이 문서는 평가 계획이며 접근성 판정이 아닙니다. 평가자(Claude Opus 5.5)는 이 조건에서 P-NONE.txt에 담긴 텍스트 자료만 읽었습니다. `https://jangwook.net/series/accessibility/overview`에 접속하거나 기사를 읽거나 조작하지 않았고, 첨부 이미지는 없습니다.

표기: **[사실]** 제공 자료에 적힌 내용 / **[가정]** 평가자가 둔 가정 / **[미확인]** 아직 관찰하지 않은 내용

**오류·팝업 상태**: [미확인] 쿠키 동의 배너, 구독 팝업, 오류 페이지 등이 나타나면 별도 상태 ID로 추가합니다.

**검사 방법 고정 분류 금지**: 예를 들어 1.1.1도 alt 속성 존재는 규칙 검사, 대체 텍스트가 이미지 목적을 전달하는지는 의미 평가, 화면 낭독기에서 실제로 읽히는지는 조작 관찰로 나뉩니다.

## C. 권장 실행 순서

1. **상태 복원**: Chromium 버전·창 크기·확대 100%·쿠키 초기화 여부를 기록하고 S0을 재현합니다. 외부 공개 사이트이므로 로그인·폼 제출은 하지 않습니다. (도구 없음 → 실행 제안)
2. **범위 확정**: "teaching video" 문구와 매체 없음 기록의 불일치를 담당자에게 확인합니다.
3. **자료 수집**: head 포함 전체 DOM, 접근성 트리, 본문 전문, 이미지 목록, 키보드 탐색 로그, 화면 낭독기 출력 로그(도구·버전 포함). (실행 제안)
4. **규칙 검사**: title·lang·alt·제목 요소·링크 이름 등 속성 수준 질문.
5. **의미 평가**: 대체 텍스트의 적절성, 링크 목적의 문맥 명확성, 색·감각 의존 표현.
6. **조작 기록 확인**: 키보드 탐색·초점 순서·문맥 변화를 로그로 확인합니다. 스크린샷만으로 확정하지 않습니다.
7. **검토와 재평가**: 판정마다 증거 ID와 반대 증거를 붙이고, 수정 후 영향받는 상태만 다시 수집합니다.

## D. AI 평가 검증 계획

- **사례 구성**: 정상 기사(구조·대체 텍스트·링크 이름 모두 적절), 단일 결함 변형(lang 누락, 제목 수준 건너뜀, 이미지 alt 누락, "여기" 같은 모호한 링크, 키보드 함정), 경계 사례(장식 이미지의 빈 alt, 문맥으로 목적이 드러나는 링크, 매체가 범위 밖 외부 임베드에만 있는 경우, 수집 기록이 일부만 있는 경우, 페이지 로드 실패)를 결함 하나씩 바꿔 구성합니다.
- **기준 답 근거 검토**: 사례마다 기대 판정과 근거(DOM 위치, WCAG 이해 문서의 해당 조건)를 기록하고, 평가 모델과 독립된 검토자 2인 이상이 합의합니다. 해석이 갈리는 사례는 경계 사례로 표시합니다.
- **오류 분류**: 오탐, 누락, 판단 유보(증거 부족을 정확히 지적했는지), 실행 실패(도구 오류를 판정으로 바꾸지 않았는지), 해당 없음 오용(매체 부재를 확인하지 않고 1.2.x를 제외했는지)을 따로 집계합니다.
- **반복 일관성**: 같은 입력을 동일 설정으로 반복 실행해 판정 일치율을 기록하고, 입력 순서·문구를 바꾼 변형에서도 비교합니다.
- **재현 비용 기록**: 실행마다 모델·노력 수준·입력 해시·소요 시간·토큰 또는 비용 추정·사람 검토 시간을 남깁니다.
- 측정 전에는 정확도·비용·완료를 주장하지 않습니다.

## F. 바로 준비할 자료 (우선순위)

1. **범위 확인 질문**: 이 기사에 평가 대상 영상이 있어야 하는지, 아니면 scope 문구가 템플릿 잔재인지.
2. **head 포함 전체 DOM과 본문 전문**: 현재는 "Published accessibility overview article." 한 줄 요약뿐입니다.
3. **환경 정보**: Chromium 버전, OS, 화면 크기, 확대 설정, 화면 낭독기와 버전 — 현재 미정.
4. **접근성 트리**: 제목·랜드마크·링크·이미지 노드.
5. **키보드 전용 탐색 로그와 초점 캡처**: S0~S2.
6. **본문 이미지·도표 목록과 대체 텍스트**.
7. **초기 팝업·배너·자동 움직임 유무**.

공개 사이트이므로 로그인하지 않고, 수집 자료에 개인 계정 정보·쿠키·인증 토큰이 포함되지 않도록 하며, 포함된 자료는 제출하지 마세요.
