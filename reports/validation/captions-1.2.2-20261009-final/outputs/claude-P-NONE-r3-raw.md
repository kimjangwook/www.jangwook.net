# P-NONE — 평가 범위·증거 수집 계획

이 문서는 계획입니다. 페이지를 방문하거나 읽거나 조작하지 않았고 접근성 판정도 내리지 않습니다. "제공됨"은 입력 JSON에 실제로 있는 내용, "가정"은 평가자 전제, "미확인"은 아직 수집하지 않은 내용입니다. 제공 자료는 기사 본문의 수집 요약(PAGE-C14)뿐이며 본문 텍스트·DOM·스크린샷은 포함되어 있지 않습니다.

## A. 평가 범위

| 항목 | 내용 | 구분 |
|---|---|---|
| 서비스 | 공개 접근성 시리즈 페이지 | 제공됨 |
| 이용 과정 | 이용자가 공개된 접근성 개요 기사를 읽음 | 제공됨 |
| 시작 조건 | https://jangwook.net/series/accessibility/overview 첫 로드(수집 기록상 HTTP 200) | 제공됨(상태 코드), 로드 화면은 미확인 |
| 완료 조건 | 안내 내용을 얻음. 실제 계정 거래 없음 | 제공됨 |

전체 사이트 평가와의 차이: 한 기사 페이지의 읽기 과정만 다룹니다. 사이트 공통 요소(헤더·내비게이션·도움말 위치의 일관성 등)는 이 범위에서 결론을 내지 않고 "미평가"로 둡니다.

입력 관련 기준(3.3.x), 2.1.4, 2.2.1, 2.3.1, 2.5.1, 2.5.2, 2.5.4, 3.2.6은 해당 요소(폼, 단축키, 시간 제한, 깜박임, 제스처, 움직임 작동, 반복되는 도움말)가 있는지 확인한 뒤 결정하며 그 전까지 "미평가"입니다. 각 기준의 적용 조건은 원문 확인 필요.

## C. 권장 실행 순서

1. **상태 복원**: 같은 URL을 Chromium으로 로드해 S0 재현(실행 제안. 현재 권한 밖).
2. **범위 확정**: 상위 scope의 "teaching video" 문구와 빈 매체 목록의 불일치를 질문으로 해소. 매체가 있으면 S2b로 전환.
3. **자료 수집**: 전체 HTML·접근성 트리·head → 이미지·링크 목록 → 키보드 조작 로그 → 보조 기술 낭독 로그.
4. **규칙 검사와 의미 평가**: 같은 기준 안에서 검사 질문별로 방법을 고름. 예) 1.1.1은 alt 존재 확인과 alt 내용이 이미지 목적에 맞는지의 의미 평가를 함께 함. 1.3.1은 마크업 확인과 시각 구조-마크업 대응 확인을 나눔.
5. **조작 기록 확인**: 키보드·보조 기술 기록으로 초점·낭독 관련 질문을 확인.
6. **검토와 재평가**: 판정마다 증거 ID와 반대 증거를 붙이고, 수정 후 같은 상태를 재수집.

## D. AI 평가 검증 계획

- **사례 구성**: 정상(매체 없는 기사, 구조 양호), 문제(이미지 alt 누락, 제목 구조 누락, 키보드 접근 불가 링크 등 한 변수씩), 경계(장식 이미지, 외부 임베드가 범위 밖인 경우, 범위 문구와 수집 기록이 충돌하는 경우, 매체가 숨겨져 있거나 지연 로드되는 경우)를 만듭니다.
- **기준 답 근거 검토**: 기준 답마다 실제 DOM 위치와 WCAG 원문 조항을 연결하고, 작성자가 아닌 검토자가 근거만 보고 재도출. 해석이 갈리면 판단 유보 허용으로 표시.
- **오류 분류**: 오탐, 누락, 판단 유보(부족한 증거를 정확히 지목했는지), 실행 실패(수집 실패를 판정으로 바꿨는지)를 따로 셈. 특히 매체가 없는 페이지에서 매체 기준을 "해당 없음"으로 둘 때 그 근거(전체 DOM 검색)를 남겼는지 확인.
- **반복 일관성**: 같은 입력의 독립 실행을 여러 번 하고 판정·근거 ID·입력/출력 해시·모델·노력 수준을 기록.
- **재현 노력**: 사람 검토 시간, 추가 요청 자료 수, 재실행 횟수를 사례별로 기록.
- 측정 전이므로 정확도·비용·평가 완료를 주장하지 않습니다.

## E. 후속 결과 기록 양식

| 상태·환경 | 기준·검사 질문 | 실행 상태 | 판정 | 증거 ID와 위치 | 사용자 영향 | 가정·반대 증거 | 수정 제안 | 재평가 조건 |
|---|---|---|---|---|---|---|---|---|
| 예: S2 / Chromium 버전 | 예: 1.2.2 — 범위 내 녹화 동기화 매체가 있는가 | 미실행 / 실행됨 / 실패 / 차단 | 미평가 / 충족 / 미충족 / 해당 없음 / 판단 유보 | 예: PAGE-C14 actual_media_inventory | (관찰 후 작성) | 예: 상위 scope 문구와 충돌 | (관찰 후 작성) | 예: 매체 추가 또는 범위 변경 시 |

- "미평가": 판정을 시도하지 않음.
- "판단 유보": 시도했으나 증거·해석이 부족함. 부족한 자료를 적음.
- "해당 없음": 적용하지 않는 이유를 적음(예: 전체 DOM 검색 결과 audio/video/iframe 없음).
- 예시 행은 형식 설명이며 실제 결과가 아닙니다.

## F. 바로 준비할 자료(우선순위)

1. 질문: 상위 scope의 "this one teaching video"가 실제로 가리키는 매체가 있는지, 아니면 템플릿 문구인지.
2. 기사 본문의 전체 HTML과 접근성 트리(head의 title·lang 포함), 수집 시점과 Chromium 버전.
3. 제외된 외부 임베드·광고 목록(범위 제외가 정당한지 확인용).
4. 이미지·도표 목록과 대체 텍스트, 링크 목록.
5. 키보드 조작 로그와 사용할 보조 기술·버전, 뷰포트·확대 설정.
6. 질문: 자동 재생 소리, 움직이는 콘텐츠, 입력 폼이 있는지.

자료를 보낼 때 로그인 세션, 쿠키, 개인정보가 담긴 캡처나 로그는 제출하지 말고 가려 주세요.
