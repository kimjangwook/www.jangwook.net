# SC 1.2.3 적용 범위 계획: jangwook.net 소개 페이지 (P-NONE)

작성 근거: 입력 프롬프트의 "[이번 실행의 실제 입력]"과 그 안의 자료 ID ABOUT-DOM(공개 HTTP 응답·DOM 문자열에서 추출한 텍스트와 태그 수)만 사용했다. 이번 실행에서 URL 방문, 렌더링 확인, 조작은 하지 않았다. 아래는 계획이며 접근성 판정이 아니다.

구분 표기: [사실]=입력으로 제공됨 / [가정]=평가자가 둔 가정 / [미확인]=아직 확인하지 않음

## A. 평가 범위

| 항목 | 내용 |
|---|---|
| 선택한 이용 과정 | [사실] https://jangwook.net/ko/about 소개 문서를 읽고 메뉴로 이동 |
| 시작 조건 | [가정] 페이지 초기 로드 상태(한국어) |
| 완료 조건 | [사실] 본문을 읽고 메뉴로 이동. 이번 실행의 완료는 1.2.3 적용 범위 계획 작성 |
| 포함 | 이 페이지 한 개에 존재하는 시간 기반 미디어 여부와, 있으면 그 대안 |
| 제외 | 링크된 다른 페이지(시리즈, 프롬프트, 아카이브 등)와 그 안의 미디어, 1.2.3 외 기준, 4.1.1 Parsing(2.2에서 삭제) |
| 목표 버전·수준 | [사실] WCAG 2.2 수준 A 중 1.2.3만. 기준 원문은 이번 자료에 없음 → 원문 확인 필요 |
| 실행 환경 | [사실] 공개 HTTP 응답과 DOM 문자열, 조작 없음. [미정] 브라우저·버전, 화면 크기, 확대, 입력 방식, 보조 기술, 수집 시점 |
| 전체 사이트 평가와의 차이 | 단일 페이지·단일 기준. 사이트의 다른 페이지 미디어에 대해서는 말할 수 없음 |

1.2.3은 사전 녹화 동기화 미디어가 있을 때 적용된다(원문 확인 필요). 따라서 이번 계획의 핵심 질문은 "이 페이지 범위에 그런 미디어가 있는가"이다.

## B. 상태와 증거 계획표

실제 관찰한 상태는 없다. ABOUT-DOM은 공급된 수집 자료이며 이번 실행에서 재수집하지 않았다.

| 상태 ID | 진입·종료 조건 | 사용자 작업 | 후보 WCAG 기준과 적용 이유 | 필요한 증거·도구 | 이미 제공된 자료 | 추가 수집 | 완료 확인 방법 |
|---|---|---|---|---|---|---|---|
| S0 초기 HTTP 응답 | 진입: 응답 수신 / 종료: DOM 확보 | 없음 | 1.2.3 적용 여부 판단의 출발점 | 원시 HTML, 수집 시점 | ABOUT-DOM: video 0, audio 0, iframe 0, 본문 텍스트 | 응답 원문, 수집 일시, 응답 헤더 | 미디어 후보 요소 목록이 증거 ID로 고정됨 |
| S1 렌더링 후 DOM | 진입: 스크립트 실행 완료 / 종료: 안정 상태 | 본문 읽기 | 1.2.3: 스크립트로 나중에 삽입되는 플레이어가 있으면 적용 가능 | 렌더링된 DOM 스냅샷, 네트워크 기록(미디어 요청 여부) | 없음 ([미확인] ABOUT-DOM이 렌더링 전/후 어느 쪽인지) | 렌더링 DOM, 미디어 MIME 요청 목록 | video/audio/iframe/object/embed 및 미디어 요청 0건 여부 확인 |
| S2 본문 읽기 | 진입: 본문 도달 / 종료: 본문 끝 | 소개 문서 읽기 | 1.2.3: 애니메이션 이미지·캔버스 등이 동기화 미디어인지 경계 판단 필요 | DOM, 스크린샷(시각 요소 확인용) | 본문 텍스트(ABOUT-DOM) | img(GIF 등)·canvas·CSS 배경 영상 여부 | 시간 기반 미디어 후보 0건 또는 목록화 |
| S3 메뉴로 이동 | 진입: 메뉴 도달 / 종료: 메뉴 링크 선택 직전 | 메뉴로 이동 | 1.2.3 직접 대상 아님. 링크 대상 페이지는 범위 밖 | 링크 목록 | 메뉴 텍스트(시리즈, 프롬프트, 소개, 언어 4종) | 없음(1.2.3 범위) | 범위 밖 기록만 남김 |

초점 이동·화면 낭독기 출력은 1.2.3과 직접 관련은 적으나, 스크린샷으로 이를 확정하지 않는다.

## C. 권장 실행 순서

1. 상태 복원: 같은 URL을 같은 언어로 로드하고 수집 시점을 기록 → 현재 도구로 불가, **실행 제안**.
2. 자료 수집: 원시 HTML과 렌더링 DOM을 모두 확보하고 네트워크에서 미디어 요청을 확인 → **실행 제안**.
3. 규칙 검사: video/audio/iframe/object/embed 태그 수, 미디어 MIME 요청 수.
4. 의미 평가: 경계 요소(애니메이션 이미지, 캔버스, 배경 영상)가 동기화 미디어인지 판단.
5. 조작 기록 확인: 본문 읽기·메뉴 이동 중 동적으로 미디어가 열리는지(모달 등) 확인 → 조작 허용 범위 확인 후 **실행 제안**.
6. 검토: 미디어 0건이 확인되면 1.2.3을 "해당 없음"으로 기록하고 이유와 증거 ID를 남긴다. 미디어가 있으면 원본 관찰 → 대안 대조 절차로 전환.
7. 재평가: 페이지 갱신(업데이트 기록 존재) 시 같은 절차를 반복.

## D. AI 평가 검증 계획

- 사례 구성: 정상(미디어 없음 → 해당 없음), 문제(동기화 영상이 있고 대안 없음), 경계(iframe 지연 삽입, 무음 GIF, 텍스트의 미디어 대안으로 표시된 영상).
- 기준 답 검토: 각 사례의 기대 결과에 DOM·네트워크 증거 ID와 원문 근거를 붙여 독립 검토.
- 결과 분류: 오탐(미디어 없는데 적용), 누락(지연 삽입 미디어를 놓침), 판단 유보(렌더링 DOM 부재), 실행 실패(수집 실패)를 구분 기록.
- 반복 일관성: 같은 자료 반복 실행 시 판정·근거 일치 여부 기록.
- 재현 노력: 수집 단계 수, 소요 시간, 사람이 확인한 항목 수 기록.
- 측정 전이므로 정확도·비용·완료를 주장하지 않는다.

## F. 바로 준비할 자료 (우선순위)

1. ABOUT-DOM의 수집 시점과 수집 방식(원시 HTML인지 렌더링 DOM인지)
2. 렌더링 후 DOM 스냅샷과 object/embed/canvas 태그 수
3. 네트워크 요청 중 오디오·비디오 MIME 목록
4. 본문 이미지 목록(애니메이션 여부)
5. WCAG 2.2 SC 1.2.3 원문
