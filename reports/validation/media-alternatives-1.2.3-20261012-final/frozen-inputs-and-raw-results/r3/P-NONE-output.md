# SC 1.2.3 적용 범위 계획 — jangwook.net 소개 페이지(/ko/about)

> 이 문서는 계획입니다. 평가자는 URL을 열지 않았고, 사이트를 조작하지 않았습니다. 사용한 자료는 입력에 포함된 `ABOUT-DOM`(공개 HTTP 응답 기반 DOM 문자열에서 추출한 텍스트와 미디어 태그 수) 하나뿐입니다. 1.2.3 판정은 내리지 않았습니다.

## 사실·가정·미확인 구분

| 구분 | 내용 |
|---|---|
| 제공된 사실 (ABOUT-DOM) | 제목 "김장욱의 관점 — jangwook.net". 건너뛰기 링크 "본문으로 건너뛰기", 내비게이션(시리즈, 프롬프트, 소개), 언어 선택(한국어, English, 日本語, 中文), 본문 소개 문단 4개 묶음, "접근성 시리즈 읽기" 링크, 푸터(아카이브, 업데이트, 개인정보 안내). DOM 전체의 `video` 0, `audio` 0, `iframe` 0. 수집은 공개 HTTP 응답과 DOM 문자열, 조작 없음. |
| 평가자 가정 | ① ABOUT-DOM의 태그 수는 수집 시점의 해당 응답 기준이다. ② 텍스트 목록은 DOM 텍스트 노드 추출이며 이미지·CSS 배경은 포함하지 않는다. |
| 미확인 | 수집 시점과 브라우저 렌더링 여부(정적 HTTP 응답인지 스크립트 실행 후 DOM인지), `object`·`embed`·`canvas`·GIF/애니메이션 이미지·CSS 배경 영상 유무, 스크립트로 나중에 삽입되는 미디어, 링크로 연결된 외부 영상(소개 페이지 밖), 언어별 페이지(en/ja/zh)의 미디어 차이. |

## A. 평가 범위

- **이용 과정:** 소개 페이지 본문을 읽고 메뉴(내비게이션)로 이동.
- **시작 조건:** `/ko/about` 로드 직후. **완료 조건:** 본문을 끝까지 읽고 메뉴 링크 중 하나로 이동 가능한 상태 확인.
- **포함:** 이 한 페이지(한국어판) 안의 사전녹화 동기화 미디어 존재 여부 확인과, 있다면 그 미디어의 대안 검토 계획.
- **제외:** 링크 대상 페이지(시리즈, 프롬프트, 아카이브 등)의 미디어, 다른 언어판, 1.2.3 이외 수준 A 기준(2.4.1 건너뛰기 링크, 3.1.1 페이지 언어, 2.4.2 제목 등은 후속 검토 대상으로만 메모). 4.1.1 Parsing은 WCAG 2.2에서 삭제되어 제외.
- **목표:** WCAG 2.2 수준 A, 이번 범위는 1.2.3만. 원문(사전녹화 동기화 미디어의 영상에 시간 기반 미디어 대안 또는 음성 해설 제공, 텍스트의 대안이고 명확히 표시된 미디어는 예외)은 평가 시점에 W3C 원문으로 재확인 필요.
- **미정 실행 환경:** 브라우저·버전, 화면 크기, 확대, 입력 방식, 보조 기술(현 도구로는 실행 불가).
- **전체 사이트 평가와의 차이:** 한 페이지·한 언어·한 기준만 다룹니다. 결과가 나와도 사이트 전체 1.2.3 상태나 페이지 전체 WCAG 적합성을 뜻하지 않습니다.

## B. 상태와 증거 계획표

모든 행은 **계획한 상태**입니다. 실제 관찰한 상태는 없습니다(ABOUT-DOM은 제공 자료이며 평가자가 수집한 관찰이 아님).

| 상태 ID | 진입·종료 조건 | 사용자 작업 | 후보 WCAG 기준과 적용 이유 | 필요한 증거·도구 | 이미 제공된 자료 | 추가 수집 | 완료 확인 방법 |
|---|---|---|---|---|---|---|---|
| S0 초기 로드(정적 응답) | HTTP 응답 수신 | 페이지 열기 | 1.2.3 적용 여부: 동기화 미디어가 있는지가 선행 질문 | HTML 원문, 태그 수 | ABOUT-DOM: video/audio/iframe 0 | `object`/`embed`/`source`/`canvas`/`img`(animated) 검색 결과, 수집 시점 | 미디어 후보 목록이 태그 종류별로 기록됨 |
| S1 렌더링 후 DOM | 스크립트 실행 완료 | 본문 읽기 | 1.2.3: 지연 삽입 미디어 여부 | 렌더링 DOM 스냅숏, 네트워크 미디어 요청 목록 | 없음(정적인지 렌더링 후인지 미확인) | 브라우저 렌더링 DOM, 미디어 MIME 요청 기록 | S0과 차이 유무 기록 |
| S2 본문 끝·메뉴 이동 | 본문 마지막 링크 도달 ~ 메뉴 이동 | 메뉴로 이동 | 1.2.3 직접 대상 아님. 링크 대상의 미디어는 범위 밖 | 링크 목록 | ABOUT-DOM 링크 텍스트 | 링크 href 목록 | 범위 밖 항목으로 분리 기록 |

스크린샷이나 텍스트 추출만으로 미디어 부재를 확정하지 않습니다. 태그 수 검사(규칙 검사)는 "동기화 미디어 요소가 있는가"라는 질문에만 답하고, 스크립트 삽입·CSS 영상은 렌더링 관찰이 필요합니다.

## C. 권장 실행 순서

1. **수집 조건 확인:** ABOUT-DOM의 수집 시점, 정적/렌더링 구분 확인.
2. **상태 복원(실행 제안):** 브라우저에서 S0·S1 재현. 현재 웹·브라우저 도구가 없어 실행하지 않음.
3. **규칙 검사:** 미디어 관련 태그 전체와 미디어 네트워크 요청 확인.
4. **의미 평가:** 미디어가 발견되면 동기화 미디어인지, 장식·순수 애니메이션인지 판단하고 1.2.3 절차로 넘김. 발견되지 않으면 해당 없음 근거를 증거 ID와 함께 기록.
5. **조작 기록:** 본문 읽기·메뉴 이동은 1.2.3과 무관하므로 미디어 발견 시에만 재생 경로 확인.
6. **검토와 재평가:** 페이지 개편·언어판 추가 시 S0·S1 재수집.

## D. AI 평가 검증 계획

- **사례 구성:** 정상(미디어 없음, 해당 없음 근거 명확), 문제(동기화 영상이 있고 대안 없음), 경계(정적 응답엔 없고 스크립트로 삽입, `iframe` 없이 `object`로 임베드, 무음 애니메이션 GIF, 영상 링크만 있는 경우).
- **기준 답 검토:** 각 사례에 태그·요청 증거 위치를 붙이고 두 번째 검토자가 원본 DOM에서 재확인.
- **오류 기록:** 오탐(미디어 없음에 미충족), 누락(삽입 미디어를 놓침), 판단 유보(렌더링 여부 미확인), 실행 실패(자료 접근 불가)를 분리 집계.
- **반복 일관성·재현 노력:** 같은 입력 반복 실행 시 판정·근거 일치 여부, 필요한 자료 수와 수작업 시간을 기록.
- 측정 전이므로 정확도·비용·평가 완료를 주장하지 않습니다.
