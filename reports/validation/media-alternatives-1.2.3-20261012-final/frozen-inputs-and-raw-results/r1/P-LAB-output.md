# SC 1.2.3 평가 범위와 증거 수집 계획 (P-LAB, r1)

이 문서는 계획이며 접근성 판정을 포함하지 않는다. 사이트 방문, 영상 재생, 원본 내용 관찰은 하지 않았다. 근거 자료는 PLAN-CONTEXT(평가 범위 기획용 설명) 하나뿐이다.

## A. 평가 범위

| 항목 | 내용 | 구분 |
|---|---|---|
| 이용 과정 | 화면을 보지 않는 이용자가 사전녹화 안내 영상(교육용 복구 코드 발급)의 정보를 대안으로 이해하는 과정 | 제공된 사실 |
| 시작 조건 | 대상 페이지 로드, 영상과 대안(대체 텍스트 설명 또는 음성 해설)에 접근 가능한 초기 상태 | 가정 |
| 완료 조건 | 원본 시각·청각 정보 단위와 대안 내용의 대응표를 만들고 SC 1.2.3 평가 범위와 증거 계획을 확정 | 제공된 사실 |
| 포함 | SC 1.2.3 Audio Description or Media Alternative (Prerecorded), 수준 A. 31초 사전녹화 영상, 시연 장면(보안 설정, 실패, 재인증, 발급, 완료), 페이지 내 대안 비교 영역 | 제공된 사실 |
| 제외 | 다른 WCAG 기준(1.2.1, 1.2.2, 1.2.5, 1.3.1, 2.1.1, 4.1.2 등)은 후속 검토. 4.1.1 Parsing은 2.2에서 삭제되어 제외. 실제 계정·발급 기능(녹화 시연이며 계정 연결 없음) | 제공된 사실 |
| 목표 | WCAG 2.2, 수준 A, 이번 범위는 1.2.3 단일 기준 | 제공된 사실 |
| 실행 환경 | Chromium/WebKit, 한국어, 1280px로 기재됨. 브라우저 버전, 확대 설정, 보조 기술, 재생기 종류는 미정 | 일부 미정 |
| 전체 사이트 평가와 차이 | 한 페이지·한 미디어·한 기준만 다룬다. 사이트 전체 대표 표본, 공통 구성요소, 다른 기준의 적합성은 이 결과로 추론할 수 없다 | 범위 표시 |

원문 확인 필요: SC 1.2.3의 "미디어 대체(media alternative for time-based media)" 정의와 "미디어가 텍스트의 대체물로 명확히 표시된 경우" 예외의 적용 조건. 현재 파일에서 원문을 읽지 않았다.

## B. 상태와 증거 계획표

모든 상태는 계획한 상태이며 실제로 관찰한 상태는 없다.

| 상태 ID | 진입·종료 조건 | 사용자 작업 | 후보 WCAG 기준과 적용 이유 | 필요한 증거·도구 | 이미 제공된 자료 | 추가 수집 | 완료 확인 방법 |
|---|---|---|---|---|---|---|---|
| S0 초기 | 페이지 로드 ~ 영상 재생 전 | 영상과 대안의 존재·위치 파악 | 1.2.3: 사전녹화 동기화 미디어인지, 미디어 대체 표시인지 판단 필요 | 전체 DOM, 접근성 트리, 영상 요소 속성(track, 설명 링크) | 없음(PLAN-CONTEXT는 설명뿐) | DOM·트리 캡처, 대안 위치 식별자 | 영상과 대안의 프로그래밍적 연결 또는 근접 배치가 자료로 기록됨 |
| S1 보안 설정 | 영상 시작 ~ 보안 설정 장면 종료 | 화면 표시 메뉴·버튼 정보 이해 | 1.2.3: 시각 전용 정보(화면 텍스트, 선택 항목)가 대안에 있는지 | 디코드된 프레임 PNG, 타임코드, ASR 전사, 화면 텍스트 기록 | 없음 | 시점별 프레임과 독립 ASR | 시각 정보 단위마다 대안 대응 여부가 표에 기록됨 |
| S2 실패 | 실패 표시 장면 | 오류 원인·표시 이해 | 1.2.3: 색·아이콘·문구로만 표시된 실패 정보의 대안 포함 여부 | 프레임 PNG, 소리 분석(경고음 등), ASR | 없음 | 오류 장면 프레임, 비음성 소리 기록 | 동일 |
| S3 재인증 | 재인증 장면 | 재인증 절차 이해 | 1.2.3: 절차 단계가 음성으로 말해지는지, 화면에만 있는지 | 프레임, ASR, 대안 텍스트 | 없음 | 단계별 대응 기록 | 동일 |
| S4 발급 | 코드 발급 장면 | 발급 결과·주의사항 이해 | 1.2.3: 화면 표시 코드·보관 안내의 대안 포함 여부 | 프레임, ASR, 대안 | 없음 | 코드 표시 장면의 텍스트(교육용 예시값만) | 동일 |
| S5 완료 | 완료 장면 ~ 영상 종료(31초) | 완료 여부 이해 | 1.2.3: 완료 표시 정보의 대안 포함 여부 | 프레임, ASR, 길이 범위 자료 | 없음 | 영상 전체 범위 자료(누락 구간 확인) | 31초 전 구간이 검토 범위로 덮였는지 기록 |
| S6 대안 비교 | 대안 영역 열람 | 대안만으로 내용 이해 | 1.2.3: 대안이 시각·청각 정보 모두를 순서대로 담는지 | 대안 원문, DOM, 필요 시 화면 낭독기 출력 기록 | 없음 | 대안 텍스트 전문 | 원본 정보 단위 대 대안 내용 대응표 완성 |

같은 1.2.3 안에서도 질문별로 방법이 다르다. 대안의 존재·연결은 DOM 규칙 검사로, 대안의 동등성은 원본 정보 단위와 비교하는 의미 평가로, 대안에 실제로 도달할 수 있는지는 조작 기록으로 확인한다. 스크린샷만으로는 대안으로의 초점 이동이나 화면 낭독기 출력을 확정할 수 없어 조작 기록이 별도로 필요하다.

## C. 권장 실행 순서

1. 상태 복원: 녹화 시연이므로 영상 타임코드로 S1~S5를 구분한다. 계정이 없어 상태 재현은 재생 위치로만 한다(실행 제안).
2. 자료 수집: 후속 제공 예정인 DOM 조작 관찰, 독립 ASR, 소리 분석, 디코드 PNG, 범위 자료를 자료 ID·수집 시점·상태와 함께 받는다. 현재 도구로는 브라우저·음성 청취·영상 처리가 불가능하므로 수집은 실행하지 않는다.
3. 규칙 검사: DOM에서 영상 요소, 대안 링크·영역, 트랙 요소를 확인한다.
4. 의미 평가: 원본 정보 단위(화면 텍스트, 동작, 비음성 소리, 말소리)를 목록화하고 대안 문장과 대응시킨다. 누락·불일치·순서 차이를 기록한다.
5. 조작 기록 확인: 키보드·보조 기술로 대안에 도달하는 기록이 있으면 대조한다. 없으면 해당 질문은 판단 유보로 남긴다.
6. 검토와 재평가: 수정 후 같은 자료 ID 체계로 다시 수집하고 이전 결과와 비교한다.

## D. AI 평가 검증 계획

- 사례 구성: 정상(모든 시각 정보가 대안에 있음), 문제(특정 장면 정보 누락, 순서 뒤바뀜, 잘못된 값), 경계(음성이 이미 시각 정보를 말해 대안 불필요할 수 있는 장면, 대안이 요약만 하는 경우, 미디어가 텍스트의 대체물로 표시된 경우)로 나눈다.
- 기준 답 검토: 각 기준 답에 근거 자료 ID와 타임코드를 붙이고 평가자 2인 이상이 원본 자료를 직접 대조한다. 의견 불일치는 기록하고 SC 원문으로 해석 근거를 남긴다.
- 오류 분류: 오탐(충족을 미충족으로), 누락(미충족을 놓침), 판단 유보(증거 부족), 실행 실패(도구 오류·자료 미수신)를 별도로 센다.
- 반복 일관성: 같은 입력으로 여러 회차를 실행해 판정·근거 차이를 기록한다.
- 재현 노력: 자료 준비 시간, 수동 확인 단계 수, 재실행 횟수를 기록한다.
- 측정 전이므로 정확도·비용·완료 여부는 주장하지 않는다.

## E. 후속 결과 기록 양식

| 상태·환경 | 기준·검사 질문 | 실행 상태 | 판정 | 증거 ID와 위치 | 사용자 영향 | 가정·반대 증거 | 수정 제안 | 재평가 조건 |
|---|---|---|---|---|---|---|---|---|
| 예: S2 / Chromium 1280px | 1.2.3 / 실패 표시가 대안에 있는가 | 미실행 | 미평가 | (수집 후 기입) | (관찰 후 기입) | | | |

- 실행 상태: 미실행, 실행됨, 실패, 차단
- 판정: 미평가(판정 시도 안 함), 충족, 미충족, 해당 없음(적용하지 않는 이유 필수), 판단 유보(시도했으나 증거·해석 부족)

## F. 바로 준비할 자료 (우선순위)

1. 영상 원본 내용 자료: 디코드된 프레임 PNG(타임코드 포함), 독립 ASR 전사, 비음성 소리 분석. 자료 ID와 수집 시점 필수.
2. 대안 텍스트 전문과 페이지 전체 DOM, 접근성 트리.
3. 31초 전 구간이 수집 범위에 포함되었는지 보여주는 범위 자료.
4. 대안 도달 조작 기록(키보드, 화면 낭독기 출력).
5. 질문: 대안은 음성 해설과 텍스트 대안 중 어느 쪽을 의도했는가? 영상이 텍스트의 대체물로 표시되어 있는가? 확대·보조 기술 환경은 무엇인가?

개인정보와 인증 정보(실제 복구 코드, 계정명, 토큰)는 제출하지 말고 교육용 예시값만 제공하도록 안내한다.

## 관찰 방식과 미검토 범위

- 사용한 방식: P-LAB-input.txt 읽기만 했다.
- 미검토: 대상 URL, 영상, DOM, 대안, 모든 PNG·관찰 자료. 판정은 하나도 내리지 않았다.
