# 소개 페이지 SC 1.2.3 적용 범위 계획 (P-NONE, r1)

이 문서는 계획이며 접근성 판정을 내리지 않는다. 사이트 방문·조작은 하지 않았고, 근거는 입력에 포함된 수집 자료 ABOUT-DOM(공개 HTTP 응답의 DOM 문자열 발췌와 태그 수 집계)뿐이다.

## A. 평가 범위

| 항목 | 내용 | 구분 |
|---|---|---|
| 이용 과정 | https://jangwook.net/ko/about 에서 소개 본문을 읽고 메뉴로 이동 | 제공된 사실 |
| 시작 조건 | 페이지 로드 직후 초기 상태 | 가정 |
| 완료 조건 | 본문을 읽은 뒤 메뉴(시리즈·프롬프트·소개·언어 전환 또는 하단 링크)로 이동 | 제공된 사실. 어느 메뉴인지는 미정 |
| 포함 | SC 1.2.3의 적용 대상 여부 판단: 범위 안에 사전녹화 동기화 미디어가 있는지 | 제공된 사실 |
| 제외 | 다른 수준 A 기준과 AA 이상 기준(후속 검토), 4.1.1 Parsing(2.2에서 삭제), 다른 언어판·다른 페이지, 링크 대상 페이지 | 제공된 사실·가정 |
| 목표 | WCAG 2.2 수준 A, 이번 계획은 1.2.3 적용 범위 | 제공된 사실 |
| 미정 환경 | 브라우저·버전, 화면 크기, 확대, 입력 방식, 보조 기술, 스크립트 실행 후 DOM 상태 | 미정 |
| 전체 사이트와 차이 | 한 페이지(ko)·한 기준만 다룬다. 시리즈 글 등 미디어가 있을 수 있는 다른 페이지에는 결과를 확대할 수 없다 | 범위 표시 |

ABOUT-DOM의 태그 수 집계(video 0, audio 0, iframe 0)는 제공된 수집 결과다. 다만 다음은 확인되지 않았다.
- 집계가 스크립트 실행 후 렌더링 DOM인지, 초기 HTTP 응답인지
- object, embed, 배경 영상(CSS), canvas 기반 재생, 지연 로드 위젯 같은 다른 미디어 삽입 경로
- 링크로 연결된 미디어 파일(링크 대상은 범위 정의에 따라 포함 여부가 달라짐)

원문 확인 필요: SC 1.2.3의 "동기화된 미디어" 정의와 "미디어가 텍스트의 대체물로 명확히 표시된 경우" 예외 문구. 이번 입력에서 원문을 읽지 않았다.

## B. 상태와 증거 계획표

아래는 모두 계획한 상태다. 실제 관찰한 것은 ABOUT-DOM 문자열 하나다.

| 상태 ID | 진입·종료 조건 | 사용자 작업 | 후보 WCAG 기준과 적용 이유 | 필요한 증거·도구 | 이미 제공된 자료 | 추가 수집 | 완료 확인 방법 |
|---|---|---|---|---|---|---|---|
| S0 초기 응답 | HTTP 응답 수신 | 없음 | 1.2.3 적용 여부: 미디어 요소 존재 확인 | HTTP 응답 원문, 태그 집계 | ABOUT-DOM(발췌 텍스트, video/audio/iframe 0) | 수집 시각, 응답 해시, object/embed/source 집계 | 집계 대상 태그 목록과 수집 시각이 기록됨 |
| S1 렌더링 후 | 스크립트 실행 완료 ~ 본문 표시 | 본문 읽기 | 1.2.3 적용 여부: 동적 삽입 미디어 | 렌더링 DOM, 네트워크 요청 목록(미디어 MIME), 스크린샷 | 없음 | 렌더링 DOM 집계, 미디어 요청 유무 | 동적 미디어 유무가 기록됨 |
| S2 스크롤·지연 로드 | 페이지 끝까지 스크롤 | 본문 끝까지 읽기 | 1.2.3 적용 여부: 지연 로드 미디어 | 스크롤 후 DOM, 네트워크 기록 | 없음 | 스크롤 후 재집계 | S1과 비교 기록 |
| S3 메뉴 이동 | 메뉴 링크 활성화 직전 | 메뉴로 이동 | 1.2.3 직접 대상은 아님. 이동 경로 확인은 후속 기준(2.1.1, 2.4.1 등) | 조작 기록(키보드) | 없음 | 후속 검토로 미룸 | 1.2.3 범위 밖으로 표시 |

같은 1.2.3 안에서도 질문에 따라 방법이 다르다. 미디어 존재는 DOM 규칙 검사로, 링크 대상이 범위인지는 범위 정의 해석으로, 미디어가 발견되면 대안 동등성은 원본과의 의미 대조로 확인한다. 스크린샷만으로는 숨은 미디어나 낭독기 출력을 확정하지 않는다.

## C. 권장 실행 순서

1. 상태 복원: 동일 URL, 동일 언어로 초기 응답과 렌더링 상태를 각각 수집(실행 제안. 현재 도구로 불가).
2. 자료 수집: 초기 응답 원문, 렌더링 DOM, 스크롤 후 DOM, 네트워크 요청 목록에 ID와 시각을 붙인다.
3. 규칙 검사: video, audio, iframe, object, embed, source, track과 미디어 MIME 요청을 집계한다.
4. 의미 평가: 발견된 미디어가 있으면 사전녹화 동기화 미디어인지, 텍스트 대체 예외에 해당하는지 판단한다. 없으면 1.2.3 해당 없음 후보로 기록하되 근거 범위를 명시한다.
5. 조작 기록 확인: 메뉴 이동은 1.2.3 판정에 쓰지 않고 후속 기준용으로 보관한다.
6. 재평가: 페이지 갱신 시 같은 집계를 반복해 변화 여부를 기록한다.

## D. AI 평가 검증 계획

- 정상 사례: 미디어 없는 페이지(이 사례 후보), 미디어와 충분한 대안이 있는 페이지
- 문제 사례: 영상은 있으나 대안이 없거나 시각 정보가 빠진 페이지
- 경계 사례: 동적 삽입 영상, 외부 임베드, 링크로만 연결된 영상, 텍스트 대체로 표시된 영상
- 기준 답 검토: 각 기준 답에 수집 자료 ID와 집계 방법을 붙이고 다른 평가자가 원 자료로 재집계한다.
- 오류 기록: 오탐(미디어 없는데 적용 대상 처리), 누락(동적 미디어 미발견), 판단 유보(렌더링 자료 없음), 실행 실패(수집 도구 오류)를 따로 센다.
- 반복 일관성: 같은 입력을 여러 회차 실행해 판정·근거 차이를 기록하고 재현에 든 단계 수와 시간을 남긴다.
- 측정 전이므로 정확도·비용·완료는 주장하지 않는다.

## F. 바로 준비할 자료 (우선순위)

1. ABOUT-DOM의 수집 시각, 수집 방식(초기 응답인지 렌더링 후인지), 집계한 태그 목록 전체
2. 렌더링 후 DOM과 미디어 MIME 네트워크 요청 목록
3. 범위 결정 질문: 링크로 연결된 다른 페이지(접근성 시리즈 등)의 미디어를 포함하는가?
4. 실행 환경(브라우저, 화면 크기)

개인정보·인증 정보(쿠키, 로그인 세션, 분석 식별자)는 수집 자료에서 제거하고 제출하지 않도록 안내한다.

## 관찰 방식과 미검토 범위

- 사용한 방식: P-NONE-input.txt 안의 ABOUT-DOM 텍스트 읽기
- 미검토: 실제 URL 응답, 렌더링 상태, 네트워크, 링크 대상 페이지. 접근성 판정 없음.
