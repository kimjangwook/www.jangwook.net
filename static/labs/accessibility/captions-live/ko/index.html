이 자료는 교육용입니다. 녹화 재생과 컴퓨터 생성 데모를 실제 생중계로 표시하지 않습니다. 아래 사례의 관찰 기록은 가정이며 실제 방송 감사 결과가 아닙니다.

직접 비교할 화면

  • 녹화 영상과 자막 재생: 재생되는 시점과 촬영된 시점은 다릅니다.
  • 화면과 소리를 코드로 생성하는 데모: 현재 생성되더라도 실세계 사건의 생중계는 아닙니다.

가정한 방송 관찰 사례

실제 방송에서는 이 전제가 맞는지 송출 기록과 시청자 화면으로 확인해야 합니다. 시나리오만으로 실제 방송의 충족 여부를 확정하지 않습니다.

L01 · 전체 자막이 표시되는 가상 방송

자료 성격: 가상 관찰

40초 전체 범위의 원음과 실제 자막 표시 기록을 같은 수신자 시계로 비교했다고 가정합니다. 대사·화자·중요한 경고음이 자막에 담기고 다른 추가 소리는 없습니다.

L02 · 부정 표현이 바뀐 자막

자료 성격: 가상 관찰

원음은 “저장하기 전에는 버리지 마세요”인데 표시된 자막은 “저장하기 전에 버리세요”입니다. 이를 바로잡는 다른 자막 경로는 없다고 가정합니다.

L03 · 화면 밖 두 패널의 발언

자료 성격: 가상 관찰

패널 A는 업데이트를 진행해도 된다고, 패널 B는 진행하면 안 된다고 말합니다. 원음으로는 목소리가 구별되지만 자막과 화면에는 각 발언을 A/B에 연결하는 단서가 없다고 가정합니다.

L04 · 대사만 있고 경고음은 빠진 자막

자료 성격: 가상 관찰

대사와 화자는 표시되지만 인증 실패를 뜻하는 두 번의 경고음 정보가 자막에 없다고 가정합니다.

L05 · 판단 화면이 닫힌 뒤 표시된 안내

자료 성격: 가상 관찰

원음과 해당 판단 화면은 14–22초입니다. “저장하기 전에는 버리지 마세요”라는 자막은 다음 작업 화면인 30–38초에 처음 표시되며 다른 대안은 없다고 가정합니다.

L06 · 서버에 생성 로그만 남은 경우

자료 성격: 가상 관찰

원음의 사건 목록과 자막 생성 로그는 있지만 이용자 화면에 전달·표시됐는지 관찰하지 않았습니다. 두 로그의 시계 차이도 모른다고 가정합니다.

L07 · 자막이 보이는 화면 한 장

자료 성격: 가상 관찰

40초 중 20초 시점의 자막 한 줄만 제시합니다. 원음, 시간축, 다른 구간과 다른 표시 경로의 기록은 없습니다.

L08 · 폐쇄 자막 대신 오픈 자막이 표시되는 경우

자료 성격: 가상 관찰

폐쇄 자막은 표시되지 않지만 같은 화면의 오픈 자막이 대사·화자·중요 소리를 전체 구간에서 정확하고 동기화된 형태로 전달한다고 가정합니다.

L09 · 기존 녹화본을 재생하는 페이지

자료 성격: 실제 제공 자료

사전에 제작된 MP4 파일을 불러와 재생한 기록입니다. 당시 생중계 제공 상태를 기록한 자료가 아닙니다.
