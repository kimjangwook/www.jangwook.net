Guide to issuing recovery codes

This is an educational guide. Do not enter real account information or codes.

An off-screen guide and user are speaking. Two warning sounds indicate a failed security check.

Full explanation

Guide: Select Security in Settings. User: Can I discard the old codes now? Guide: No. Do not discard them before saving the new recovery codes. [Two warning sounds indicating a failed security check] Guide: Complete the security check again, then confirm issuance. Guide: Save the new codes in a safe place. Once new codes are issued, the old codes can no longer be used. Guide: Check the issuance complete screen. The on-screen guidance has the following seven steps. Security settings Select Security in Settings. Open Security Question about old codes Listen to the question and answer, then proceed to the next step. Listen to the answer Before discarding codes Check that the new codes have been saved first. Check saved status Security check result Check the result and proceed to the next step. Check the result Repeat the security check Complete the security check and confirm issuance. Security check Save new codes Keep the codes in a safe place. Saving complete Issuance complete Check the issuance complete screen. Return to Settings
