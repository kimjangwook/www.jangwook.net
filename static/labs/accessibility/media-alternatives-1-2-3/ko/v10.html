복구 코드 발급 안내 본문

이 자료는 복구 코드 발급 안내 영상과 같은 정보를 같은 순서로 제공합니다. 실제 계정에서 사용할 수 없는 교육용 가상 화면입니다. 1. 보안 설정 화면에는 ‘설정 → 보안 → 복구 코드’ 경로와 ‘새 코드 발급’ 버튼이 보입니다. 안내자는 “설정에서 보안을 선택합니다.”라고 말합니다. 사용자가 “이전 코드를 지금 버려도 되나요?”라고 질문합니다. 2. ‘발급 전 확인’ 화면에서 이전 코드 유지 버튼과 “새 코드를 저장하기 전에는 이전 코드를 버리지 마세요.”라는 경고가 나타납니다. 안내자는 “아니요. 새 복구 코드를 저장하기 전에는 버리지 마세요.”라고 답합니다. 3. 보안 확인 실패 화면에서 “보안 확인에 실패했습니다. 다시 인증해 주세요.”라는 문구와 ‘보안 확인 다시 하기’ 버튼이 나타납니다. 보안 확인 실패를 알리는 경고음이 두 번 울립니다. 4. 재인증 완료 화면에서 “보안 확인이 완료되었습니다. 새 코드 발급을 확인하세요.”라는 문구와 ‘발급 확인’ 버튼이 나타납니다. 안내자는 “보안 확인을 다시 끝낸 뒤 발급을 확인합니다.”라고 말합니다. 5. 새 복구 코드 화면에는 교육용 가상 코드 R7K2-P9M4와 “이 화면의 코드는 실제 계정에서 사용할 수 없습니다.”라는 안내 및 ‘코드 저장’ 버튼이 보입니다. 안내자는 “새 코드를 안전한 곳에 저장합니다. 새로 발급하면 이전 코드는 더 이상 사용할 수 없습니다.”라고 말합니다. 6. 발급 완료 화면에 “새 코드 저장 완료 · 이전 코드 사용 불가”와 ‘설정으로 돌아가기’ 버튼이 나타납니다. 안내자는 “발급 완료 화면을 확인합니다.”라고 말합니다. 영상 속 버튼은 시연 화면이며 실제로 누르는 조작은 없습니다. 페이지의 영상 플레이어는 재생·일시 정지·탐색을 제공합니다.
