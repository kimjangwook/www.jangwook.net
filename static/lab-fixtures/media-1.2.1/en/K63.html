Teaching example. Failure cases intentionally omit or distort information.

Silent video source · English

Provided text alternative

  1. In Account settings, the page says you must be signed in before creating a recovery code. Choose Open Security.
  2. Security explains that recovery codes restore account access; choose Create recovery code.
  3. Before you continue warns that a new code makes the previous code unusable. Choose Confirm new code.
  4. Recovery code created instructs you to save it safely and says that this example shows no real code. Choose I saved my code.
  5. Complete says that the new code is ready and the previous code can no longer be used. Choose Return to settings.
