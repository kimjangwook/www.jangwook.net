제공된 텍스트 대안

  1. 계정 설정: 복구 코드를 발급하려면 로그인되어 있어야 합니다. 보안 열기를 선택합니다.
  2. 보안: 복구 코드는 계정 접근을 복원하는 데 도움이 됩니다. 복구 코드 발급을 선택합니다.
  3. 계속하기 전에: 새 코드를 만들면 이전 코드는 사용할 수 없게 됩니다. 새 코드 확인을 선택합니다.
  4. 복구 코드 발급 완료: 안전한 곳에 저장합니다. 이 예시는 실제 코드를 표시하지 않습니다. 코드를 저장했습니다를 선택합니다.
  5. 완료: 새 코드가 준비되었으며 이전 코드는 더 이상 사용할 수 없습니다. 설정으로 돌아가기를 선택합니다.
