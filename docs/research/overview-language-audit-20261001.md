아카이브의 다국어 글 보존과 새 시리즈의 다국어 지원은 다르다. 새 사이트 공통 내비게이션도 현재 한국어이며, 새 시리즈에 언어 선택 연결이 없다. 새 시리즈는 한국어 정본 검토 단계다. 이미지 생성 코드 역시 한국어 문구가 고정되어 있으며, 언어별 자산을 자동으로 선택하는 구현은 없다.

## 다국어 제공에 필요한 작업

- 한국어 정본의 동일한 판본에서 영어·일본어·중국어 본문과 프롬프트를 번역하고 검수한다.
- 도식의 라벨·코드 예시 중 사용자에게 전달되는 문구·SVG title/desc·대체 텍스트·캡션을 같은 언어로 제작한다. 이미지 파일만 교체하고 캡션을 한국어로 남기지 않는다.
- 각 언어의 실제 SSR 경로, 언어 선택, 제목·요약·목차·내비게이션·자료 안내를 연결한다. 기존 한국어 경로와 보관 글 URL은 보존한다.
- html lang, Open Graph locale, 구조화 데이터 inLanguage와 상호 hreflang을 실제 제공 내용에 맞춘다. 존재하지 않거나 승인되지 않은 번역 경로를 공개 대체 언어로 표시하지 않는다.
- 각 언어의 도식 자산 정체성을 원고 승인 해시에 포함하고, 모바일·no-JS·PDF에서 글자 잘림과 언어 혼합을 검증한다.

최초 요청의 작업 범위는 현황 확인이었다. 아래는 이후 사용자의 네 언어 제공 및 전체 문서 사전 생성 지시에 따라 구현한 변경이다.

## 후속 구현: 네 언어 및 전체 문서 사전 생성

첫 개요의 본문·프롬프트·네 도식·대체 텍스트·캡션을 네 언어로 제공한다. 영어·일본어·중국어는 한국어 정본에서 직접 번역하고 별도 모델 요청으로 원문과 대조했다. 영어 1건, 중국어 3건을 수정했고 일본어는 수정 요구가 없었다. 각 프롬프트의 출력 언어 지시는 대상 언어에 맞춘 의도적 변경이다. 모델·사용량·검토 결과·도식 해시는 reports/translations/accessibility-overview-provenance.json에 기록한다.

88편 × 네 언어의 SSR 경로와 제목·요약을 제공한다. 후속 87편 본문은 준비 중이며 목차·이전/다음·언어 전환이 모두 작동한다. 준비 페이지는 noindex,follow로 표시하며 RSS·sitemap 글 항목에서 제외한다. 번역 누락을 한국어 본문으로 대체하지 않는다.

최초 원시 점검 보고서는 이력으로 보존했다. 현재 브라우저·352개 경로 검증은 reports/series-language-validation.json, 언어별 도식의 글자 맞춤은 reports/translations/diagram-layout.json에 기록한다. 로컬 Worker 결과는 reports/worker-validation.json을 참조한다. 이번 작업은 로컬이며 공개 발행·배포가 아니다. 기존 한국어 PDF는 그대로 보존했고 이번 변경으로 번역 PDF를 생성하지 않았다.
