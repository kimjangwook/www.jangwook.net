# 비텍스트 콘텐츠 네 언어 공개

사용자의 “네가지 언어 완성하여 배포.” 요청은 한국어 검토본 r3의 본문과 최종 프롬프트, 영어·일본어·중국어 간체 번역 및 운영 배포를 승인한다. 해당 원고와 검토 PDF 해시를 reports/releases/non-text-content-20261003/user-approval.json에 연결했다.

네 언어 모두 본문·프롬프트·체크 항목 12개·도식 4개·대체 텍스트·캡션·도식 내부 문구를 제공한다. 번역은 한국어 정본에서 직접 작성하고 별도 원문 대조를 거쳤다. 기준·조건·예외·실제 실행 결과를 보존하며, 번역 프롬프트의 출력 언어와 예제 문자열을 현지화했다. 번역 과정은 새로운 접근성 모델 검증 실행을 의미하지 않는다.

기존 /series/accessibility/non-text-content 및 /en, /ja, /zh의 같은 준비 페이지 주소를 공개 글로 전환한다. 각 언어의 정확한 본문 해시를 승인하며 초판 공개일과 수정일, SSR 요약·BlogPosting·시리즈 관계·RSS·sitemap을 일치시킨다. 시리즈 전체 88편 중 공개 글은 개요와 1.1.1 두 편이며 나머지 86편은 준비 페이지를 유지한다. 자료받기 폼과 메일은 아직 활성화하지 않는다.

본문 학습 링크는 독자의 언어로 렌더링하고, 공개 본문의 정확한 배포 버전을 article-source-sha256 메타데이터로 확인한다. 기존 아카이브 경로와 Journey 공통 태그, 빌드 시 갱신하는 ads.txt를 보존한다.

이전 운영 릴리스의 독립 Git 스냅샷에서 이번에 승인한 파일만 반영해 배포한다. 원래 작업 폴더의 무관한 변경을 커밋하거나 푸시하지 않는다. 배포 전 실제 운영 버전은 a911bb61-55a4-462c-b5ab-cfc937c4a891이며 복구 명령은 다음과 같다.

    npx wrangler rollback a911bb61-55a4-462c-b5ab-cfc937c4a891 --name www-jangwook-net --env production

운영 배포 영수증과 실제 URL 검증 결과는 reports/releases/non-text-content-20261003에 별도로 기록한다. 저장된 승인·로컬 검사만으로 운영 배포 완료를 주장하지 않는다.
