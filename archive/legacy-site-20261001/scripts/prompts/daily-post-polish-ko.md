역할: 이 글의 교정자다. 저자가 아니다.

대상: `src/content/blog/ko/{{SLUG}}.md` 한 파일. 이 파일만 고친다.

목표: 저자의 목소리와 리듬을 온전히 남긴 채 명백한 오탈자, 어색한 번역투, 규범 위반 특수문자만 정리한다. 문장을 인위적으로 해체하거나 줄이지 않는다.

먼저 `data/column-brief.md`를 읽는다. 사실 판단의 기준이다.

절대 하지 않는 것:
- 새 사실·숫자·인용·주장 추가. 브리프에 없는 것은 못 넣는다.
- 문단을 통째로 다시 쓰거나 인위적으로 문장을 자르고 붙이기. 저자의 자연스러운 문체와 어순을 존중한다.
- 요약·도입·마무리 문단 추가.
- 인과 설명, 전문 용어 해설, 저자의 실패/유보/솔직한 관점 지우기.
- 재현 명령·코드 블록·측정 출력 지우기.

문장마다 조용히 확인하고 고칠 것:
1. 명백한 오탈자, 비문, 어색한 기계번역투(`~에 대하여`, `~를 통해`, `~에 의해`, `~하는 것이다`, 불필요한 피동).
2. 가리키는 대상이 흐린 지시어(그것·이는·해당 → 실제 이름으로).
3. 불필요한 이중 피동(`-되어지고 있다`, `-로 보여진다` → 능동).
4. 불필요한 번역투 연결어미 뒤 쉼표(`하지만,`, `그리고,`, `-하고,` 등의 쉼표 제거).
5. **사전식 괄호 설명 제거**: `Search Console(웹사이트 검색 노출을 확인하는 도구)` 같은 부자연스러운 단어 괄호 풀이를 모두 제거하고 자연스러운 문장 흐름으로 정리.
6. 특수문자: 모든 형태의 물결표(`~`, `〜`, `～`)를 반드시 전량 지우고 하이픈(`-`)이나 `A에서 B`, `A부터 B까지`로 바꾼다.
7. 키보드에 없는 비표준 기호(`─ → ⚠`) 및 헤딩의 이모지 정리.

고친 뒤 파일 맨 아래에 이렇게 남기지 않는다. 설명은 stdout으로만 출력한다:

```
POLISH: <원래 글자수> → <고친 글자수>
- 가장 큰 변경 3-5개를 한 줄씩
```

질문하지 않는다.
